# 1 자료 개요

- 사용자 지정 원자료 16장에 수록된 합동무의 구성과 26개 번호 항목을 원문 순서대로 요약한 참고 자료임. 준비, 반복, 연결, 인사와 퇴장을 포함하므로 26종의 서로 다른 춤을 뜻하지 않음.
- 원자료 하단의 책 제목은 「남사당의 덧뵈기」이며, 확인 범위는 제7장 「덧뵈기의 춤」의 370~385쪽임. 저자, 출판사, 발행 연도와 판차는 미확인임.
- 춤사위의 동작, 장단, 진행 방향과 전환 조건을 구분하고, 사용자가 `06_자산/이미지/덧뵈기/춤사위`에 정리한 이미지 23장을 해당 항목에 삽입함.
- 본문은 원문 전사가 아닌 요약임. 원저자의 설명을 정리한 것으로, 공연 영상 대조나 기획 적용 여부 판단은 포함하지 않음.

## 2.2 요약과 이미지 대응 원칙

- 사용자가 지정한 원본 이미지 16장을 직접 대조함. 작업 공간의 기존 설명이나 다른 기획 문서를 동작 설명의 근거로 사용하지 않음.
- 아래 춤사위별 설명의 묶음 제목은 검색과 열람을 위한 편집 분류임. 원문의 네 장 구분이나 새로운 공연 단계로 간주하지 않으며, 각 항목의 `원문 번호`로 기존 순서를 보존함.
- 동작 방향과 신체 좌우는 원문 서술 기준임. 사진을 보는 사람의 좌우로 바꾸지 않음. 한삼, 오금 등의 전문 용어는 원문대로 사용함.
- 본문 도해는 모두 지정된 자산 폴더의 기존 파일임. 7번의 패턴 도해는 두 장이며, 13번, 23번, 24번과 25번은 원자료에 독립 도해가 없어 설명만 수록함.
- 자산의 파일명, 규격과 원자료 대응은 [덧뵈기 춤사위 이미지](<../06_자산/이미지/덧뵈기/춤사위/덧뵈기 춤사위 이미지.md>)에 기록함. 자료의 수집과 정리를 기획 채택이나 동작 구현의 승인으로 취급하지 않음.

# 3 합동무의 구성과 장단

## 3.1 합동무를 기준으로 한 정리

- 원저자는 대표 명칭인 나비춤과 닭이똥사위 이외의 춤사위 정리가 부족하다고 설명하고, 덧뵈기의 기본무에 해당하는 합동무의 순서에 따라 명칭과 내용을 기술함. 출처는 370쪽의 도입 설명임.
- 원문에 나열된 큰 흐름은 `입장춤 → 불림소리 → 합동춤 → 나비춤 → 너울질 → 팔걸이 → 쌍줄백이 → 앉을 사위 → 맺는 사위 → 퇴장`임. 출처는 370~371쪽의 합동무 개괄임.
- 원문은 위 나열을 `9개의 큰 틀`로 설명하지만, 나열된 명칭을 구분하면 10개임. 원문의 수량과 나열을 함께 보존하며 어느 쪽도 정정 확정하지 않음.

## 3.2 원문에 제시된 네 장

출처는 371쪽의 합동무 개괄임. 아래는 장별 요약이며, 번호별 상세 설명의 반복과 전환을 모두 열거한 목록은 아님.

| 원문 구분 | 원문에 나열된 춤사위 순서 |
|---|---|
| 1장 | 입장춤(텅텅걸음), 어르기, 좌우새, 나비춤, 연결체, 너울질, 닭이똥사위, 방아사위, 엿보는 사위, 맺는 사위 |
| 2장 | 나비춤, 활갯짓, 너울질, 제자리돌기, 쌍줄백이 |
| 3장 | 팔걸이, 너울질, 닭이똥사위 |
| 4장 | 앉을 사위, 나비춤, 제자리돌기, 인사, 퇴장 |

- 개괄의 `활갯짓`은 번호별 설명에서 `활개 치기`로 제시함. `엿보는 사위`는 11번 방아사위 설명 안에 포함되어 있으며 독립 번호 항목은 없음.
- 개괄에서는 팔걸이 다음에 쌍줄백이를 나열하지만, 번호별 상세 설명은 18번 쌍줄백이 다음에 19번 팔걸이사위를 설명함. 상세 설명은 번호 순서를 따름.

## 3.3 도해의 장단표 읽기

- 다수 도해에는 네 묶음의 숫자와 구음이 함께 실려 있음. 아래는 372쪽 어르기와 이후 여러 도해에 반복되는 표기를 옮긴 것임. `빈칸`은 원자료의 공란을 표시하며 쉼이나 동작 정지를 뜻한다고 해석하지 않음.

| 행 | 첫째 묶음 | 둘째 묶음 | 셋째 묶음 | 넷째 묶음 |
|---|---|---|---|---|
| 숫자 | 1, 2, 3 | 2, 2, 3 | 3, 2, 3 | 4, 2, 3 |
| 구음 | 덩, 빈칸, 빈칸 | 딱, 빈칸, 기 | 덩, 빈칸, 딱 | 얼, 빈칸, 쑤 |

- 입장춤의 구음은 `덩`의 반복으로, 맺는 사위는 첫 묶음이 `더, 더, 더`로, 퇴장은 덩덕궁이 구음으로 제시됨. 각 도해의 표기를 우선 확인함.
- 어르기 도해에는 `녹수-한삼에 심불-로--`, `저리저리 얼쑤 절쑤`로 이어지는 불림소리 두 행이 있음. 음절의 칸별 배치와 공란은 삽입 이미지에 보존함.
- 사진 칸은 동작의 예시이며, 이를 영상의 연속 프레임이나 정확한 재생 시간으로 치환하지 않음. 분당 박수, 장단별 실제 소요 시간과 동작 사이 궤적은 제공 자료만으로 확인하지 못함.

### 4.1.2 좌우새, 나비춤과 연결

#### 1) 좌우새

# 5 확인 범위와 미확인 사항

## 5.1 확인한 범위

- 원자료 16장의 인쇄면 370~385쪽, 도입과 합동무 개괄, 번호 항목 1~26, 동작 설명과 도해를 직접 대조함.
