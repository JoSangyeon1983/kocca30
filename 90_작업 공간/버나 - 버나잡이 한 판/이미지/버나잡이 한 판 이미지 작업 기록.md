## 6.2 현재 재검증

- [이미지 통합 기록 검증 도구](<../../../00_시스템/03_도구/image_record_check.py>)로 최종 이미지 해시와 PNG 규격, 라벨의 철자와 횟수, 전사 불확실 여부, 프롬프트 보존과 기획서 이미지 경로 확인함. 실행 결과는 표준 출력으로 반환하며 별도 결과 파일 생성 없음.

```powershell
python 00_시스템/03_도구/image_record_check.py "90_작업 공간/버나 - 버나잡이 한 판/이미지/버나잡이 한 판 이미지 작업 기록.md"
```

- 로컬 아카이브 파일 보존도 대조하려면 같은 명령 끝에 `--archive` 추가함. Git에서 제외된 아카이브가 없는 환경에서는 기본 검증만 수행함.
- 2026-10-14 출처 정리 후 기획서 본문과 이미지 연결은 유지함. 기계 대조 데이터의 기획서 해시는 2026-10-12 당시 스냅샷으로 보존하므로 `article_matches_snapshot`은 `false`임. 현재 이미지 대상과 로컬 링크 검증은 통과함.
- 이미지의 새 생성이나 수정은 작업별 `작업중/날짜_대상_변경내용` 폴더에서 수행하고, 검수 통과 후 최종 이미지를 반영함. 통합 기록 갱신 후 중간 폴더를 아카이브로 이동함.
