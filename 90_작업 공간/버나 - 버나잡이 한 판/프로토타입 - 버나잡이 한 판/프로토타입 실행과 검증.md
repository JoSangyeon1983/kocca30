# 1 실행

- [버나잡이 한 판](<버나잡이 한 판.html>)을 브라우저에서 열어 실행함. 서버와 패키지 설치 불필요.
- HTML과 동봉한 `data.js`, `balance.js`, `app.js`를 같은 폴더에 유지함.
- A는 왼쪽 기울임, S는 오른쪽 기울임, 좌우 방향키는 이동, Space는 띄우기, R은 재시작임. 기울임과 이동은 키를 누르는 동안 적용함.
- 화면의 물체 선택과 시험 설정으로 물체별 수치 조정 가능. 화면 변경값은 현재 실행에만 적용하며 새로 열면 파일의 값으로 시작함.
- 각도 직접 시험에서 막대 각도를 지정하거나 0도로 돌려 구간별 반응 확인 가능.

# 2 구현한 규칙과 입력 근거

- 사용자가 지정한 [요구사항: 버나 균형 시스템](<요구사항.md#21-버나-균형-시스템>)과 2026-10-14 대화의 정정 내용을 직접 구현 입력으로 사용함. 다른 기획 문서에서 규칙을 추가하지 않음.
- 접촉 중에는 막대 각도의 절댓값으로 복원, 유지, 증가와 낙하를 판정함. 변화 대상은 버나 기울기이며 복원과 증가에 같은 변화 속도 적용함.
- 막대 0도에서는 버나가 점진적으로 0도까지 복원되고 그대로 유지됨. 증가 시에는 버나가 이미 기울어진 방향을 유지함. 공중에서는 같은 속도로 복원함.
- 버나의 시계 반대방향 회전은 조작과 기울기에서 독립적으로 일정하게 유지함. 낙하 시 현재 물체로 재시작하며 물체의 자동 단계 진행 없음.
- 버나, 대접과 대야는 수동 선택으로 각각 시험함. 복원값을 조정하면 복원 구간이 달라짐.

# 3 시간 처리와 시험용 가정

## 3.1 시간 처리

- 초당 각도 변화량을 기준으로 실제 경과 시간만큼 진행함. 화면은 `requestAnimationFrame`으로 갱신하고 내부 계산은 초당 120회 고정 간격으로 수행함.
- 화면 프레임 수가 증가해도 같은 시간의 기울기 변화와 회전량이 같도록 구성함. 구현 참고: [MDN requestAnimationFrame의 시간 기반 갱신 안내](<https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame>).
- 기존 예시의 프레임 당 1도, 2도, 3도는 초당 60회 기준으로 60도, 120도, 180도로 환산함. 초당 60회는 사용자 확정 수치가 아닌 초기 환산 가정임.
- 탭을 숨기거나 포커스를 잃으면 입력을 해제함. 화면 갱신이 오래 중단된 경우 한 번에 따라잡는 시간은 0.1초로 제한함. 실제 장시간 정지 후의 벽시계 경과 시간 전체를 재현하지 않음.

## 3.2 시험용 수치와 예외

아래 내용은 동작하는 초안을 만들기 위한 구현 가정이며 최종 기획 확정값이 아님.

| 항목 | 이번 구현 |
|---|---|
| 버나가 0도에서 증가 구간 진입 | 막대가 기울어진 방향으로 증가 시작 |
| 막대 기울임 | 초당 32도, 최대 좌우 45도. 키를 놓으면 해당 각도 유지 |
| 좌우 이동 | 초당 220 좌표 단위, 중앙 기준 좌우 240 이내 |
| 일정 회전 | 초당 120도, 화면상 시계 반대방향 |
| 띄우기 | 비행 시간 1.1초, 최고 높이 130 좌표 단위. 공중에서도 막대 끝의 가로 위치를 따라감 |
| 재접촉 | 비행 종료 시 막대 끝에 자동으로 복귀. 재접촉 시 막대가 한계값 이상이면 낙하 |
| 낙하와 재시작 | 낙하 표시 1초 후 막대와 버나 각도 및 위치 초기화. 선택한 물체와 조정한 데이터 유지 |

# 4 데이터와 파일

- 물체별 원본 데이터: [버나 데이터.json](<버나 데이터.json>). `tiltSpeed`는 초당 변화량, `restore`는 복원값, `hold`는 유지값, `limit`는 한계값임.
- 브라우저용 데이터: [data.js](<data.js>). 로컬 HTML에서 데이터 로딩 제약 없이 실행하도록 원본 JSON에서 생성함. 직접 수정하지 않음.
- 구현: [balance.js](<balance.js>)는 판정과 상태 갱신, [app.js](<app.js>)는 조작과 화면 표시 담당.
- 원본 JSON 변경 후 위키 루트에서 다음 명령 실행함.

```powershell
node "90_작업 공간/버나 - 버나잡이 한 판/프로토타입 - 버나잡이 한 판/build.cjs"
```

# 5 검증 결과

## 5.1 판정과 시간 검증

- Node.js v22.20.0에서 [verify.cjs](<verify.cjs>)의 19개 검증 묶음 통과함.
- 세 물체의 좌우 대칭, 정확한 경계값, 점진 복원과 0도 초과 방지, 유지 및 기존 기울기 방향 증가 확인함.
- 공중 복원, 재접촉 시 낙하 판정, 동일 물체 재시작과 막대 기준 낙하 확인함. 버나 각도에 별도 종료값을 적용하지 않음.
- 30회, 60회와 144회 화면 갱신을 가정한 동일 시간 시험에서 기울기와 회전량 일치 확인함. 회전의 조작 및 비행 독립성, 데이터 일치와 잘못된 설정 거부 확인함.

```powershell
node "90_작업 공간/버나 - 버나잡이 한 판/프로토타입 - 버나잡이 한 판/verify.cjs"
```

## 5.2 브라우저와 화면 검증

- 별도 임시 프로필의 숨김 Edge 155.0.4283.45에서 로컬 HTML 실행함. 사용자의 기존 브라우저 프로필에는 연결하지 않음.
- A와 S 키 입력, 증가와 유지 표시, Space 띄우기와 공중 복원, 왼쪽 한계값 낙하 및 자동 재시작 확인함.
- 물체 선택과 설정 검증, 390픽셀 화면의 가로 넘침 없음, JavaScript 실행 예외 없음 확인함. 결과: [브라우저 검증.json](<브라우저 검증.json>).
- 1280×900 실행 화면에서 막대와 버나, 현재 각도, 조작 버튼과 설정 패널의 배치를 시각 확인함. [검증 화면](<검증 화면.png>)은 이 로컬 구현에서 캡처한 화면이며 외부 이미지 자산을 사용하지 않음.

```powershell
node "90_작업 공간/버나 - 버나잡이 한 판/프로토타입 - 버나잡이 한 판/browser-verify.cjs"
```

# 6 한계와 미확인 범위

- 실제 손과 센서 입력, 실제 버나 물리, 체험 재미와 적정 난이도는 미검증임.
- 공중 가로 이동과 자동 재접촉은 단순화한 시험 규칙임. 공중 복원 느낌은 사용자 플레이 후 추가 조정 대상임.
- 대접과 대야의 표시는 형태를 단순화한 도형임. 모바일의 가로 넘침만 자동 검사했으며 실제 터치 기기 조작과 다른 브라우저는 미검증임.
- 작업 공간의 구현 초안으로 유지함. 정식 프로토타입 반영이나 기획 근거 채택을 수행하지 않음.
