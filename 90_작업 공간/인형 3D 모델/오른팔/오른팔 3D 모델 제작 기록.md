# 1 결과와 범위

- 사용자 지정 오른팔 이미지의 외곽과 정면 질감을 사용한 별도 기초 3D 모델 제작함. 소매의 남색 천과 황토색 직조 무늬, 나무 손 및 원본의 대각선 자세를 유지함.
- 이전 인형과 같은 로컬 근사 제작 방식 사용함. AI 복원 모델이 아니며 보이지 않는 깊이와 뒷면은 가정한 형태임.
- 몸통과 결합하거나 관절, 뼈대와 애니메이션을 추가하지 않음. 별도 오른팔 GLB이며 검토 상태로 작업 공간에 보관함.

# 3 입력과 제작 방법

## 3.1 입력과 도구

- 사용자 첨부 `C:\Users\cellbig\Documents\ArmR.png`만 외곽과 정면 질감의 입력으로 사용함. 원본 수정하지 않음.
- [모델 제작.py](<../모델 제작.py>)의 메시 생성, GLB 내보내기, 검사와 소프트웨어 렌더 함수를 재사용함. [미리보기 틀.html](<../미리보기 틀.html>)에서 오른팔용 뷰어 생성함.
- 이번 작업에는 MCP 유료 생성 작업이나 생성 프롬프트 사용하지 않음. 로컬 Python, NumPy, OpenCV와 Pillow 및 JavaScript 구문 검사용 Node.js 사용함.

## 3.2 형상과 질감

- 알파 영역의 주된 연결 요소를 추출하고 어깨에서 손으로 향하는 대각선 축을 기준으로 횡단 폭을 추정함. 추정 폭에 둥근 앞뒤 두께를 부여하고 6픽셀 간격 격자를 원본 외곽에 맞춰 자름.
- 정면에는 원본 이미지를 투영함. 추정 뒷면에는 같은 소매 질감을 활용하고 나무 손의 색상 영역을 단순한 나뭇결로 보완함.
- 앞뒤 표면을 외곽에서 연결한 닫힌 메시로 제작함. 소매 입구의 어두운 부분, 접힘과 손가락 경계는 원본 투영 그림을 포함한 근사 표현임. 실제 소매 내부 공간이나 분리된 손가락 관절 모델이 아님.
- 기존 인형과 같은 임의 척도인 원본 1픽셀당 0.001미터 적용함. 몸통과의 비례 및 부착 위치는 실제 결합 검증 전 상태임.

## 4.2 시각 검토와 미확인 범위

- 정면, 45도, 측면과 추정 뒷면의 소프트웨어 렌더를 직접 확인함. 남색 소매의 직조 무늬와 소맷단, 나무 손 및 대각선 자세 식별 가능함.
- 측면에서는 표면 그림의 늘어짐과 손가락 형태의 단순화가 남아 있음. 보이지 않는 뒷면과 두께가 실물과 일치하는지는 확인 불가함.
- HTML의 실제 WebGL 실행과 회전 조작, Blender 및 게임 엔진의 실제 가져오기, 몸통과의 결합, 리깅과 3D 프린팅 적합성 미검증임.
