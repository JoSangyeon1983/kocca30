# 1 결과와 적용 범위

- 사용자 제공 인형 정면 이미지에 두께를 부여한 기초 3D 모델 제작함. 원본 정면의 비율, 얼굴 그림, 팔 없는 외곽과 의상 색상 보존을 우선함.
- 이미지 외곽을 부풀린 메시와 원본 투영 질감으로 제작함. AI 기반 다면 복원 결과가 아니며 깊이와 뒷면은 제작자가 정한 근사 형태임.
- 작업 공간의 검토용 결과이며 기획 문서나 확정 자산으로 채택하지 않음. 뼈대와 애니메이션 미포함함.

# 3 입력과 제작 방법

## 3.1 입력 자료

- 사용자 첨부 `C:\Users\cellbig\Documents\head_body.png`만 형태와 정면 질감의 입력으로 사용함. 원본 파일 수정하지 않음.
- 사용자의 낮은 품질 허용 및 이미지 기반 인형 3D 모델 제작 요청을 작업 범위로 적용함. 다른 위키 기획 문서는 형태나 규칙의 근거로 사용하지 않음.

## 3.2 MCP 자동 생성 시도

- Higgsfield 모델 목록과 Meshy 7의 이미지 기반 3D 모델 규격 확인 후 원본 업로드 완료함.
- 예정 옵션: `model_type=standard`, `target_polycount=10000`, `topology=triangle`, `should_texture=true`, `should_remesh=true`, `enable_pbr=false`, `enable_rigging=false`, `enable_animation=false`, `ultra_mode=false`.
- 이미지 생성 비용 조회 경로에서 `model is a 3d model; use generate_3d instead` 오류 반환함. 현재 연결에 전용 `generate_3d` 도구가 노출되지 않음을 확인함.
- 브라우저 연결 도구와 Windows 컴퓨터 조작 런타임도 초기화 오류 발생함. 유료 생성 작업은 제출되지 않았으며 Meshy AI 생성 결과 없음.
- 사용자에게 제한과 로컬 근사 제작 방식으로 진행할 내용을 알린 뒤 로컬 제작함. 로컬 제작에는 생성 프롬프트 사용하지 않음.

## 3.3 로컬 근사 모델링

- 알파 외곽에서 주된 인형 영역을 추출하고 삼각형 격자를 외곽에 맞춰 잘라냄. 작은 알파 잡음은 외곽 처리 과정에서 제외됨.
- 머리, 목, 몸통과 다리의 깊이를 구간별로 가정하고 앞뒤 표면 생성함. 코와 허리 매듭 위치에 얕은 돌출을 추가함.
- 정면은 원본 이미지를 투영함. 뒷머리와 나무 표면은 단순한 절차 질감, 뒷면 의상은 원본 의상에서 추출한 천 질감으로 구성함. 실제 뒤통수 모양이나 복식의 뒷면 구조를 입증하는 자료는 없음.
- 형상과 앞뒤 질감을 단일 GLB에 내장함. 모형 크기는 원본 이미지 1픽셀을 임의로 0.001미터에 대응한 작업 척도이며 실물 치수와 무관함.

## 3.4 소요 시간

- 전체 작업은 현재 대화의 제작 지시 수신부터 완료 보고까지의 경과 시간으로 계산함. 날짜는 2026-10-15, 시각은 한국 표준시(Asia/Seoul) 기준임.

## 4.2 시각 검토

- 정면, 45도, 측면과 뒷면을 소프트웨어 래스터 렌더로 직접 확인함. 정면의 얼굴 그림, 큰 머리 비율, 남색 상의, 황토색 허리띠, 흰 바지와 짚신 식별 가능함.
- 첫 뒷면 질감에서 두드러진 반복 무늬를 확인하여 뒤통수와 나무 질감을 단순한 절차 질감으로 교체한 뒤 네 방향 재검토함.
- 앞뒤 질감의 연결선과 투영된 그림의 측면 늘어짐이 남아 있음. 허리띠 끈과 짚신 끈, 옷 주름은 독립 부품이 아닌 표면 그림 중심 표현임.

## 4.3 미확인 범위

- 브라우저 실행 도구 오류로 HTML의 실제 WebGL 로딩과 회전 조작은 미확인임. 내장 JavaScript의 Node 구문 검사만 수행함.
- Blender, Unity와 Unreal Engine에서 실제 가져오기 미수행함. 리깅, 애니메이션, 3D 프린팅 적합성과 실제 크기 미검증임.
- 원본에 없는 뒷면과 깊이의 일치 여부는 검증 불가함. 이 결과를 정교한 전방향 인형 모델 또는 AI 자동 복원 모델로 취급하지 않음.

# 5 재생성

- Python, NumPy, OpenCV, Pillow와 Node.js가 필요함. 추가 패키지 설치 없이 현재 로컬 환경의 패키지 사용함.
- 원본 경로는 모델 제작.py의 `SOURCE`에 기록함. 다른 컴퓨터에서는 실제 원본 위치에 맞춰 변경함.

```powershell
python "90_작업 공간/인형 3D 모델/모델 제작.py"
```

- 재생성 시 같은 폴더의 모델, 입력 사본, 확인 이미지와 미리보기 HTML을 덮어씀. 사용자 원본은 덮어쓰지 않음.
