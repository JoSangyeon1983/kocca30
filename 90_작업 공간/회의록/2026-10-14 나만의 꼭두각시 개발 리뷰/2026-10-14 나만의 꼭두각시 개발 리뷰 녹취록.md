- 원본에 표시된 발언자: 김승현(총괄), 김정환(RnD), 조상연(기획), 오승철(아트), 윤요섭(클라이언트), 이기혁(RnD), 안진용(아트)임. 이름과 역할은 TXT 표기를 유지하며 원음으로 별도 확인하지 않음.
- 원본의 `참석자 8`은 사용자 후속 확인에 따라 안진용(아트)으로 교정함. T0146과 T0207에 적용함. TXT 첫머리의 역할 없는 `조상연`을 별도 참석자로 중복 계산하지 않음.
- T0001 등의 표시는 완성본 기록 ID, C0001 등의 표시는 최초 추출 ID임. T0107을 제외한 T 기록은 발언이며 T0107은 편집자 설명임. 각 기록 아래 TXT의 원래 구간과 필요한 교정 대응을 기재함. 줄 번호는 TXT의 첫 행을 1로 하고 빈 행을 포함해 계산함.
- 클로바의 한 화자 구간에 여러 사람의 발언이 합쳐지거나 겹칠 수 있음. 기록 ID와 개수는 편집 구간의 식별 정보이며 실제 발언 횟수나 화자 전환 횟수를 뜻하지 않음. 사용자 확인이 없는 화자 표기는 원문 기준의 잠정 표기임. 문구 교정이나 기록 간 일치 확인만으로 구간 안의 모든 문장이 같은 사람의 발언임을 확정하지 않음.
- 사용자 수정본에서 종전의 미확인 및 추정 표시를 정리함. 현재 발언은 2항, 이전 표현과 판단은 대조표의 최초 교정문 및 최초 판단에서 구분함. 말줄임표는 이어지지 않는 구어 표현을 나타냄. 편집자 주는 실제 발언과 구분하며, 사용자 편집으로 제외된 구절은 대조표에서 추적함.
- “이렇게”, “여기까지”, “앞에 거” 등의 지시 표현은 보존함. 몸짓, 화면의 실제 위치와 앞서 진행된 다른 회의 내용은 복원하지 않음. R&D는 연구개발, RFP는 제안요청서, UI는 사용자 인터페이스, AI는 인공지능, JSON은 데이터 교환용 텍스트 형식, UV는 이미지와 표면을 대응시키는 좌표를 가리키는 표기임. 약어 설명은 편집자의 독해 안내임.

# 3 교정과 미확인 사항

## 3.1 교정 근거와 적용 범위

- 현재 녹취는 사용자가 직접 수정한 2항을 기준으로 함. 이전 편집본과 다른 56개 기록을 반영하고, 이번 요청에 따라 중복 입력 7곳과 T0132의 호명만 추가 정리함.
- [2026-10-14 나만의 꼭두각시 개발 리뷰 대조표](<2026-10-14 나만의 꼭두각시 개발 리뷰 대조표.md>)는 원문, 최초 교정문, 현재 교정문과 판단 이력을 구분함. 최초 판단의 미확인 표현을 현재 발언의 상태로 읽지 않도록 표시함.
- 회의록 정리에는 현재 2항의 내용과 기록 ID를 사용함. 원본 TXT는 수정하지 않고 교정 근거와 원래 위치를 추적하는 자료로 보존함. 완료한 대조는 재사용하고, 주요 결정이나 의미의 불일치가 다시 문제 되는 부분만 필요한 원자료를 재확인함.
- 사용자 교정은 발언 복원과 편집의 근거임. 회의의 제안이 채택되었다는 승인이나 기술 및 가격 정보의 외부 검증으로 확대하지 않음.

사용자가 생략한 구절은 현재 발언에 다시 넣지 않음. 원문과 최초 교정문에 남겨 생략 위치를 확인할 수 있게 함. 전체 56개 변경 구간의 표현과 현재 처리 근거는 대조표에 기록함.

## 3.3 보존한 의견 차이와 조건

- T0048~T0050의 제품 존재 여부 의견 차이, T0058~T0061의 도구 연동과 콘텐츠 개선에 관한 관점 차이 보존함.
- T0065~T0070 및 T0078의 영상 활용 가능성에 대한 조건과 재고 과정, T0091~T0092의 좌우 반전과 회전 구분 보존함.
- T0112~T0151의 프로젝트 통합과 분리 의견, 규격 미정 및 빌드 분리 의향을 발언 순서대로 유지함. 최종 통합 방식이 결정되었다는 문장을 추가하지 않음.
- T0184~T0185의 스크립트 작성 요청과 재공유 확약, T0201~T0204의 11월 검토와 납품 완료 범위 질문 및 개선 가능성 조건 보존함. 담당이나 날짜를 추정하여 보충하지 않음.
- T0205~T0209의 끈과 철사 연출 제안, 마리오네트 방식과 다르다는 설명을 각각 유지함. 관련 발언을 사실 검증이나 전통 조작 방식의 확정 설명으로 바꾸지 않음.

## 3.4 검토 범위와 남은 한계

- 원문 인식 구간 214개와 현재 기록 214개의 ID, 시각, 순서 및 원래 줄 범위를 확인함. 현재 구성은 발언 내용을 담은 편집 구간 213개와 편집자 설명 1개이며, T0053~T0054의 경계 조정과 T0107~T0108의 중복 인식 처리를 별도 표시함.
- 사용자 수정본 56개 구간과 중복 입력 7곳, 요섭 씨 호명 확인을 반영함. 대조표의 현재 교정문 214개는 녹취록의 각 기록과 일치하도록 갱신함.
- 원본 TXT 두 위치의 파일, 최초 추출 JSON과 기획서는 변경하지 않음. 사용자 편집으로 삭제된 훼손 구절은 대조표 원문 및 최초 교정문에서 보존함.
- 원음, 몸짓과 화면 자료는 미확인임. 사용자 교정의 음성 확인 여부 또는 기억에 따른 복원 여부는 별도 확인하지 않음. 2항에서 미확인 표시가 사라진 것을 원음 대조 완료로 해석하지 않음.
- 가격, 제품 존재 여부, 기술 적합성 및 사업계획서 언급의 사실성과 승인 권한은 별도 검증하지 않음. 회의록 작성 시 제안, 결정, 조건과 후속 작업을 해당 발언의 의미에 따라 구분해야 함.

## 3.5 화자 표기의 확인 범위

- 현재 제공 자료와 사용자 교정의 대조 범위에서 추가로 교정해야 할 화자 오류는 확인되지 않음. T0143, T0091, T0169와 T0179의 기존 확인 우선순위는 문맥상 혼재 가능성에 대한 편집자의 해석이었으며, 필수 잔여 교정 항목에서 제외함.
- T0143은 오승철(아트), T0091은 윤요섭(클라이언트), T0169와 T0179는 오승철(아트) 표기 유지함. 질문 뒤 응답형 표현, 해결안 제시나 말 고침만으로 다른 화자의 발언이 섞였다고 판정하지 않음. 발언 문구와 원문 대응 유지함.
- 원음 미대조와 클로바 화자 분류의 일반적인 한계는 유지함. 확인 후보에서 제외한 것은 실제 음성의 화자 확인 완료나 모든 화자 표기의 정확성 보증을 의미하지 않음. 구체적인 오류 근거나 추가 자료가 생기면 해당 구간을 재검토함.
- 회의록 작성 시 제안, 결정과 후속 작업은 해당 발언의 근거와 확인 범위로 판정함. 짧은 응답형 표현만으로 별도 참석자의 동의나 회의 전체의 합의를 만들지 않음.
