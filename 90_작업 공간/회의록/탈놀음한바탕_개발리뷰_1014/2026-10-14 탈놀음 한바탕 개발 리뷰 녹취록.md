# 3 교정과 미확인 사항

## 3.1 현재 편집 결과

| 항목        | 결과                                                                                      |
| --------- | --------------------------------------------------------------------------------------- |
| 전체 기록     | 원문 구간 381개와 현재 기록 T0001~T0381의 ID, 시각 및 원문 위치 대응 유지함                                    |
| 현재 수정본    | 최초 교정 데이터로 재현한 본문과 95개 구간에서 다름. 현재 표현, 최초 교정문과 원문은 교정 대조표에서 구분함                         |
| 화자 변경     | T0086은 안진용, T0142와 T0161은 김승현으로 현재 교정본의 표기를 반영함. 원문 표기는 추출 자료와 대조표에 보존함                 |

- 이전의 수정 260건과 미확인 108건은 최초 편집 때의 집계임. 현재 녹취의 미확인 개수나 현재 수정본의 검증 완료 수치로 사용하지 않음. 최초 기록은 교정 대조표와 검증 결과 JSON의 이력으로 보존함.
- 현재 자료는 사용자가 회의록 입력으로 지정한 수정본임. 발언 복원과 생략, 화자 변경을 실제 원음 확인 결과로 표시하지 않음.

## 3.2 확인 범위와 한계

- 원본 TXT의 SHA-256, 381개 추출 구간의 원문 위치와 현재 기록의 대응을 확인함. 최초 교정 이력, 현재 수정본 및 중복 글자 정리를 구분해 기록함.
- T0317의 답변은 끝나지 않은 문장이므로 스크립트 작성 완료를 판정하는 근거로 사용하지 않음. 미니게임 수의 3개와 4개 언급은 정정 과정으로 보존하고, 장비와 영상 제작 방식은 논의된 제안의 범위로 기록함.
- 원음, 수기 기록과 화면 자료는 미제공 또는 미확인임. 편집자 주에서 제외한 구간의 화자 혼재나 불완전한 구절을 결정 및 담당 판정에 사용하지 않음.
- 현재 교정본과 교정 이력으로 회의록을 작성할 수 있음. 원음 미대조와 외부 사실 미검증의 한계를 유지하며, 추가 확인을 회의록 작성의 선행 조건으로 두지 않음.
