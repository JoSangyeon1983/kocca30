# 1 작업 개요

- 목적: [문진수본 - 옴탈잡이: 현대어 풀이](<../../05_참고 자료/연희본 현대어 풀이/문진수본 - 옴탈잡이.md#5-현대어-풀이>) 전체를 A4 세로 만화로 제작하기 위한 페이지와 컷, 대사 및 이미지 생성 입력의 작업안임.
- **구성 제안**: 8페이지, 총 46컷임. 대사 길이와 동작의 변화에 따라 나눈 결과이며 페이지 수와 컷 수는 조정 가능함.
- 대사: 현대어 풀이의 31개 발화 문단을 54개 말풍선에 원문 순서대로 배정함. 문구와 문장부호를 유지하고 말풍선 경계만 나눔. 괄호 안 지문은 그림 연출로 반영함.
- 제작 상태: 작업 문서 초안임. 2026-10-21 P01~P08의 PNG 8개를 생성하고 46컷과 말풍선 54개의 문자 및 기본 화자 연결을 대조함. 아래 생성 결과에서 페이지별로 열람 가능함. 사용자 승인과 실제 인쇄 검수는 수행 전임.

## 1.1 입력과 적용 범위

| 입력 | 적용 항목 | 이 문서에서의 용도 |
|---|---|---|

| [만화 연출 기법 정리](<만화 연출 기법 정리.md>) | A4 세로 지면, 컷 분할, 컷 연출, 말풍선과 대사 표시, 캐릭터와 공간의 일관성, 이미지 생성용 입력 작성 | 사용자 지정 제작 가이드임 |

- 기준 시점: 2026-10-21에 확인한 파일 내용임. 버전 번호는 부여하지 않음.
- 페이지 분할, 컷 형태, 카메라, 말풍선 위치와 출구의 화면 좌우는 이 문서의 **연출 설계**임. 입력 문서에서 새로 확인한 사실로 서술하지 않음.
- 대사 중 모자와 얼굴을 비유하는 표현은 발화로 표시함. 참조 이미지의 모자를 떡시루로 바꾸거나 붉은 탈을 누런 탈로 바꾸지 않음.
- 원문 대응 기록의 U ID는 입력 문단, 하위 ID는 행동과 상태의 변화, P ID는 페이지, C ID는 컷, D ID는 출력 문자열을 식별함. 이 ID는 만화에 표시하지 않음.

# 2 공통 제작 조건

## 2.1 지면과 읽는 순서

- A4 세로 210 × 297 mm, 바깥 여백 상하좌우 12 mm, 컷 배치 영역 186 × 273 mm로 제안함. 출력용 작업 크기는 가이드의 약 2480 × 3508 px를 목표로 하되 생성 파일의 실제 규격은 반환 후 확인함.
- 독서 방향은 왼쪽에서 오른쪽, 위에서 아래로 설정함. 같은 행을 읽은 뒤 다음 행으로 이동함.
- 컷의 간격은 아래 레이아웃의 상대 좌표를 따름. 가이드의 직사각형 예시에서 사용한 4 mm 간격을 모든 다각형에 동일하게 적용한 배치는 아님.
- 일반 대사 글자는 최종 A4에서 12 pt를 시작값으로 검토함. 긴 대사는 글자 축소보다 말풍선의 폭과 연결, 컷의 면적을 조정함.
- 만화 내부의 전체 제목, 페이지 번호, 화자명, 컷 ID와 효과음은 현재 출력 목록에서 제외함. 원문의 대사와 노래 문자열만 표시함.

## 2.2 인물과 공간의 연결

- 옴탈 입장 후의 기본 화면 위치는 **옴탈 왼쪽, 꺽쇠 오른쪽**임. 두 인물이 마주 보는 시선축을 유지함.
- 입장은 꺽쇠를 중심으로 반시계 방향, 멈추는 위치는 9시 방향임. 입장 동선을 보여 주는 컷에서 이 관계를 드러냄.
- 옴탈이 화면 왼쪽으로 먼저 물러나고 꺽쇠는 오른쪽에 남아 춤을 마무리함. 마지막 꺽쇠도 같은 왼쪽으로 나감. 좌우는 기존 인물 위치를 이어 정한 연출 설계임.
- 악사는 마지막 문답에서 화면 밖 왼쪽 후경의 화자로 처리함. 말풍선 꼬리는 화면 밖으로 향하게 함. 첫 장면의 연주자 퇴장은 중앙 놀이판에서 물러나는 모습으로 처리함.
- 탈의 고정된 눈과 입, 복식과 소품을 유지함. 감정은 고개와 어깨, 몸 기울기와 발 위치로 표현함.

# 4 컷 레이아웃

- 각 레이아웃의 원점은 바깥 여백을 제외한 컷 배치 영역의 왼쪽 위임. 오른쪽 아래를 (100, 100)으로 두고 x는 오른쪽, y는 아래로 증가함.
- 꼭짓점은 시계 방향임. 가로 좌표는 폭, 세로 좌표는 높이에 대한 비율이므로 좌표값 1의 mm 길이는 두 축에서 다름.
- 표의 S 번호가 컷의 읽는 순서임. 페이지의 C01은 S1, C02는 S2에 대응함.
- 다각형의 좁은 꼭짓점 부근은 여백과 짧은 동작선에 사용함. 얼굴과 손의 접점, 긴 대사는 넓은 부분에 배치함.
- 사선은 컷 경계를 정하는 선임. 인물과 배경 전체를 기울이는 카메라 지시로 사용하지 않음.

# 5 페이지별 콘티와 출력 문자열

- 각 페이지의 출력 문자열 표에 있는 문구가 렌더링 기준임. 행바꿈은 말의 호흡에 맞추되 단어와 문장부호를 유지함.
- 한 행은 말풍선 1개이며 각 D ID를 지정 컷에 1회씩 배정함. 동일 문자열을 가진 서로 다른 D ID는 각각 출력함.
- `일반`은 흰 둥근 말풍선, `외침`은 각진 돌기 말풍선임. `불림`과 `노래`는 완만한 물결 테두리를 사용하되 대사 판독을 우선함.

## 5.1 P01 놀이판과 낯선 손님

- 입력 범위: [문진수본 - 옴탈잡이: 현대어 풀이](<../../05_참고 자료/연희본 현대어 풀이/문진수본 - 옴탈잡이.md#5-현대어-풀이>) 중 본문 이미지 1의 풀이임.
- 레이아웃: L6C, 가로 컷과 사다리꼴 6컷임.

## 8.3 사용자 원문 수정 대응

- 2026-10-21 사용자 수정한 현대어 풀이 312~330행을 반영함. 새 원문 단위는 기존 ID 뒤 r1을 붙여 구분하고 원래 추출 행은 아래에 이전 기록으로 보존함. 해당 ID는 검토용 식별자이며 문서 버전 번호가 아님.
