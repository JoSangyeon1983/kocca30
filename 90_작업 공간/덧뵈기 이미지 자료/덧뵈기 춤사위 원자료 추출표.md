# 1 추출 범위와 기준

- 사용자 지정 `참고이미지/50_춤사위_01.png`부터 `50_춤사위_16.png`까지 16장을 처음부터 끝까지 직접 확인한 최초 추출 기록임.
- 범위는 인쇄면 370~385쪽의 도입 설명부터 합동무 26번 퇴장과 마지막 도해까지임.
- 도입 설명, 원문의 번호별 동작 설명과 그에 딸린 도해, 별도 패턴과 각주 표지를 구분함. 페이지가 갈려도 같은 원문 번호의 설명과 도해는 같은 단위로 추출함.
- 아래 ID는 원자료 대응용 식별자이며 새로운 춤사위 분류나 게임 단계 번호가 아님. 장단표의 사진 칸을 독립 춤사위로 세지 않음.

# 3 대조 시 유의 사항

- C02의 나열 명칭은 10개이지만 원문은 9개의 큰 틀로 기술함. 수량 불일치를 임의로 수정하지 않음.
- C03은 장별 개괄, A01~A26은 준비와 반복 및 전환을 포함한 세부 항목임. 26개를 서로 다른 춤 유형 수나 게임 단계 수로 치환하지 않음.
- A20의 닭이똥사위와 방아사위 관계는 문구상 불명확함. 오기로 확정하거나 다른 동작으로 대체하지 않음.
- A07의 박자와 장단 표현 및 일부 동작 용어는 원문에서 혼용됨. 실제 공연 시간이나 연속 궤적으로 확장하지 않음.
- 별도 자산 파일명에서 `팔걸이사위`는 `19_팔걸이사위.png`로, `입장춤(텅텅걸음)`은 `02_텅텅걸음.png`로 대응함. 파일명 자체는 변경하지 않음.
