# 1 작업 목적과 현재 상태

- 현재 제작 방식: 동일한 시작과 종료 이미지, 동작 이미지와 캐릭터 시트만 사용하는 방식임. 기존 8칸은 화풍과 신체 비율 차이로 사용자 미채택함. 현재는 시작과 종료 PNG를 체형 기준으로 사용한 [개별 러프 8개와 제작 기록](<../../06_자산/이미지/덧뵈기/꺽쇠 입장춤/꺽쇠 입장춤 동작 레퍼런스 제작 기록.md#6-개별-러프-8장-제작>)을 준비함. 원본 영상은 자세 분석에만 사용하고 러프에는 복식과 얼굴 묘사를 제외함. 합치는 작업은 사용자가 직접 수행하므로 합성본을 만들지 않음. 이번 작업에서 새 영상은 생성하지 않음. 아래 영상 생성 결과들은 이전 시도의 기록임.

- 최신 시도: 동일한 시작 및 종료 이미지, 원본 17초 영상과 간결한 프롬프트를 사용한 [씨댄스 원본 참조 결과](<../../08_산출물/덧뵈기/등장 애니메이션/꺽쇠/꺽쇠 입장춤 씨댄스 2.5 원본 참조.mp4>)를 사용자 지시대로 1개 생성함. 풍경과 줌 및 시작과 종료 이미지 불일치가 남아 조건 미충족임. 아래 상태는 이전 시도의 기록임.

- 현재 상태: 사용자가 이후 Seedance 2.5로 1번 다시 생성하라고 지시하여 [1회 생성 결과](<../../08_산출물/덧뵈기/등장 애니메이션/꺽쇠/꺽쇠 입장춤 씨댄스 2.5 1회 결과.mp4>)를 보관함. 약 20초, 1:1과 무음은 확인했으나 회색 여백과 화면 변화, 붉은 소매 천 및 춤 시간 배치의 문제로 조건 미충족임. [씨댄스 생성 기록](<../../08_산출물/덧뵈기/등장 애니메이션/꺽쇠/꺽쇠 입장춤 씨댄스 2.5 생성 기록.md>)에서 확인함. 이 지시에 따른 제출은 1회이며 추가 재생성 없음. 앞서 보관한 [17초 본춤](<../../08_산출물/덧뵈기/등장 애니메이션/꺽쇠/꺽쇠 입장춤 본춤 17초.mp4>)은 별도로 유지함. 아래 재생성 변경 조건을 우선 적용함.
- 탈놀음 한바탕에서 꺽쇠가 등장할 때 사용할 춤 애니메이션의 제작 조건과 참조 자료를 정리한 작업 메모임.
- 2026-10-20에는 사용자 요청에 따라 문서화까지만 수행함. 2026-10-21 영상 생성 실시와 크로마키 적용 요청에 따라 제작 재개함.
- 2026-10-21 녹색 크로마키 영상 2개를 생성하고 2차를 전달용 검토안으로 보관함. [꺽쇠 등장 크로마키.mp4](<../../08_산출물/덧뵈기/등장 애니메이션/꺽쇠/꺽쇠 등장 크로마키.mp4>)는 9.041667초, 1,916 × 1,080, 24fps, 무음임. 과정과 미채택 이유는 [제작 기록](<영상 제작/2026-10-21 꺽쇠 등장/제작 기록.md>), 현재 파일과 검수 범위는 [산출물 제작 기록](<../../08_산출물/덧뵈기/등장 애니메이션/꺽쇠/꺽쇠 등장 애니메이션 제작 기록.md>)에서 관리함.
- 아래 사용자 지정 조건과 이미지 레퍼런스 구성 제안을 구분함. 여러 컷의 중간 자세 이미지는 필수 조건이 아니므로 이번 시도에서는 별도 생성하지 않음.

## 3.2 입장춤에서 참고할 내용

- 첫 박에 한 발과 한 손을 사용해 뛰어나오는 입장춤으로 설명됨. 원문의 장단 명칭은 일채, 내드림과 난타 등임.
- 첫 박에 오른발을 내딛고 팔의 좌우새를 함께 하며 좌우를 번갈아 진행하는 설명을 참고함.
- 장단이 빨라지면 제자리에서 돌며 멈추는 설명을 참고함. 실제 애니메이션의 회전 포함 여부와 범위는 영상 분석 후 정함.
- 원문의 `왼손에 좌우새`는 구체적인 팔의 좌우 대응이 불명확함. 임의로 대응을 확정하지 않고 영상과 대조함.

# 4 이미지 레퍼런스 구성 제안

## 4.1 목적과 역할

- 여러 컷의 이미지 레퍼런스는 필수 조건이 아닌 제작 제안임. 원본 영상의 춤을 좁은 이동 범위와 10초 이내로 재구성한 결과를 생성 전에 확인하는 용도임.
- 영상은 리듬과 동작 연결, 지정 PNG는 외형과 시작 및 종료 자세, 여러 컷의 이미지는 재구성한 주요 자세와 순서를 확인하는 데 사용함.
- 모든 컷의 카메라, 캐릭터 크기와 바닥 높이를 통일하고 발 위치와 좌우 이동 범위를 표시하는 안임.

## 4.2 컷 구성안

| 순서 | 내용 |
|---|---|
| 시작 1컷 | 지정한 꺽쇠 서 있는 자세 PNG 사용함. |
| 중간 3~4컷 | 영상과 입장춤에서 선택한 핵심 춤 자세를 좌우 두 걸음 이내에 맞춰 구성함. |
| 종료 1컷 | 시작과 동일한 PNG의 자세와 구도로 복귀함. |

- 전체 5~6컷의 제안이며 개별 동작, 컷 수와 시간 배분은 미정임.
- 한 장으로 묶은 콘티와 개별 컷을 함께 준비하는 안임. 실제 생성 입력은 선택한 모델의 영상 참조, 이미지 참조 및 시작과 종료 프레임 지원 방식에 맞춰 정함.

# 5 제작 절차와 검수 항목

1. 45초 원본 영상에서 발 디딤, 팔 동작, 몸의 반동과 회전 및 장단의 구간을 분석함.
2. 대표 동작을 선택하여 10초 이내의 순서와 시간 배분을 구성하고 좌우 이동 범위 및 시작과 종료 자세를 대조함.
3. 필요한 주요 자세를 지정 캐릭터에 적용하여 여러 컷의 레퍼런스 이미지를 만들고 동작과 외형의 일관성을 확인함.
4. 생성 모델과 입력 방식, 해상도와 화면비, 배경 처리 및 음원 사용 방식을 정함. 2026-10-21 첫 시도는 Seedance 2.5, 영상 참조와 동일 시작 및 종료 이미지, 1080p, 16:9, 녹색 크로마키와 무음으로 제출함. 첫 시도는 잘림과 복식 변형으로 미채택함. 2차는 Kling v3.0, 동일 시작과 종료 프레임 및 동작 서술, 9초와 무음 설정으로 생성하고 실제 규격을 대조함.
5. 영상 제작 후 전체 길이, 이동 범위, 시작과 종료 자세, 캐릭터 외형과 동작 연결을 검수함. 실제 사용 영상은 위키의 산출물 관리 기준에 따라 파일과 제작 기록을 함께 관리함.

# 6 재생성 변경 조건

- 춤의 직접 참조는 [꺽쇠_입장춤_0.mp4](<영상자료/꺽쇠_입장춤_0.mp4>) 17초 전체로 변경함. 춤사위 문서와 기존 텍스트 동작 순서 및 다른 영상 구간은 새 춤의 입력에서 제외함.
- 화면비는 1:1, 카메라는 고정, 배경은 녹색 크로마키임. 지정 PNG는 외형과 정면 정지 자세의 기준으로만 사용함.
- 정면의 서 있는 자세에서 춤으로 자연스럽게 들어가고, 춤을 마친 뒤 정면의 서 있는 자세로 복귀해야 함. 원본의 카메라 줌과 추적을 복제하는 것은 요청 범위가 아님.
- 사용자가 약 20초 구성 설명 후 생성을 지시함. 17초 본춤을 영상 입력이 있는 모션 컨트롤로 생성하고, 앞뒤 정면 자세 연결은 별도로 추가함. [재생성 제작 기록](<영상 제작/2026-10-21 꺽쇠 입장춤 모션 전이/제작 기록.md>)에서 실제 제출과 검수 범위 관리함.
- 원본을 그대로 입력한 첫 모션 전이에서는 줌과 잘림, 화면비 및 길이 불일치를 확인하여 미채택함. 카메라 보정 참조를 입력한 2차도 잘림으로 제외함. 이미지 구도 설정을 적용한 3차에서 17초와 1:1 및 전신을 확인함. [본춤 제작 기록](<../../08_산출물/덧뵈기/등장 애니메이션/꺽쇠/꺽쇠 입장춤 본춤 제작 기록.md>)에서 실제 검수와 미완료 범위를 관리함.
