# 2 탈놀음 한바탕

## 2.1 의견

- 동작 인식 우려 제기
    - 유저의 동작이 기획서에 있는대로 인식될 지 우려 제기
- 시나리오 중심으로 진행하는 것을 제안
    - 유저가 배역으로서 극에 개입하고 유저의 행동에 따른 시나리오 분기가 있었으면 함
    - 원래 진행에 소품이 없는데 소품을 활용하는 것이 맞지 않음

# 3 버나잡이 한 판

## 3.1 의견

- 막대의 회전을 물체의 회전에 연동하는 구현이 어려울 경우 시스템을 간소화하자는 의견 제시
    - 물체는 회전을 계속 유지하고 기울기만 막대로 조정하여 균형을 잡는 시스템 제안
	- 던질 사위는 유지
- 인형을 튕기는 방식보다 튕기지 않도록 유지하는 방식이 더 자연스럽다는 의견 제시
    - 현재 인형을 튕기는 것이 목적인데 인형이 튕기지 않도록 하는 것이 더 자연스러울 거 같음
