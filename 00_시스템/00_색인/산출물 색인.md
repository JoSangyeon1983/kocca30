# 1 이용 안내

- 사용, 전달과 발표용 파일 및 기존 제작 자산과 검토용 구현을 한곳에서 찾기 위한 목록임. 관리 기준은 [위키 작업 지침: 사용과 전달용 산출물](<../../AGENTS.md#46-사용과-전달용-산출물>)과 [문서 형식: 산출물](<../01_규정/문서 형식.md#12-산출물>)을 따름.
- 별도로 사용하는 출력 파일과 관리 기록은 `08_산출물`에 보관함. 원본 문서, 제작 자산과 실행 프로젝트는 해당 역할의 위치를 유지하고 이 색인에서 연결함.
- 아래 검토 상태는 관리 기록의 현재 `status`임. 파일 존재 여부, 내용 검증과 회사 승인 여부는 각각 구분함. 파일을 반환한 것만으로 검토 상태를 높이지 않음.
- 일괄 파일 상태 확인일은 2026-10-19임. 옴탈 서 있는 자세의 방향 수정과 정면 구도 보정 및 해당 PNG의 추가 검증일은 2026-10-20이며 아래 해당 행에 구분함. 자산과 검토용 구현은 기록과 로컬 경로를 대조함. 사용자가 배치한 XLSX 3개는 읽기 가능 여부와 전체 셀 값 및 생성 당시 추출 데이터의 일치까지 추가 확인함. 새 시각 검수는 수행하지 않음.

# 6 확인 범위와 한계

- `01_프로젝트`부터 `08_산출물` 및 `90_작업 공간`의 활성 Markdown 49개에서 `asset_files`와 인식 가능한 본문 로컬 경로를 대조함. 웹 URL, 코드 블록의 예시, 외부 첨부 원본과 과거 로그의 당시 경로는 현재 파일의 반환 목록으로 사용하지 않음.
- 활성 관리 기록의 파일 경로 124개는 모두 존재함. 기존 자산과 모델의 내용 검증은 해당 관리 기록의 당시 범위를 유지함. XLSX 3개는 사용자 배치 후 ZIP과 XML 무결성, Artifact Tool 읽기 및 전체 셀 값 대조를 수행함.
- 보관 문서는 `asset_files`의 파일 존재와 동명 파일 후보를 확인하여 현재 기록과 구분함. 과거 경로의 동명 후보는 동일본으로 단정하지 않으며, 이전 XLSX 2개는 지정한 보관 위치의 실제 파일을 읽어 생성 당시 추출 데이터와 대조함. 보관 원문 전체 파일의 당시 해시와 현재 해시가 달라 이번에는 원문 전체의 동일성까지 검증한 것으로 취급하지 않음.
