# 3 폴더 안내

## 3.1 상위 폴더

| 폴더 | 역할 |
|---|---|
| `00_시스템` | 색인, 운영 규정, 작업 기록과 도구 |
| `01_프로젝트` | 과제 원본과 공식 기록 |
| `02_기획 근거` | 채택 결정과 적용 범위가 확인된 정보와 조건 |
| `03_기반 기획` | 상세 기획의 방향, 조건과 공통 규칙을 정의하는 기획 |
| `04_상세 기획` | 적용 가능한 기반 기획을 구체화한 기획 |
| `05_참고 자료` | 조사 원문, 사례와 참고용 분석 |
| `06_자산` | 제작하거나 가공한 이미지, 영상, 음원과 도표 등 |
| `07_프로토타입` | 검증용 구현과 검증 기록 |
| `90_작업 공간` | 개인 초안, 아이디어, 대안 검토와 피드백 반영 작업 |
| `99_보관소` | 이전 기획, 종료 작업과 미채택 자료의 로컬 보관. Git 추적 제외 및 밖에서 내부로 연결하는 링크 금지 |

- 하위 폴더는 실제 보관 내용이 있을 때 생성함. 작성 중인 회사 업무 기획서도 기반 또는 상세 기획 폴더에서 관리하며 파일 위치와 승인 상태를 구분함.
