# 1 용도와 파일

- [행동 안내 시안.html](<행동 안내 시안.html>)은 사람들에게 보여줄 소품 건네기와 던지기 자동 안내의 재생 시안임.
- 파일을 열면 별도 조작 없이 재생 시작함. 배경과 팔 보정 이미지 및 코드가 모두 포함된 단일 HTML이므로 이 파일 하나를 다른 폴더에 복사해 전달 가능함. 서버, 인터넷 연결과 추가 파일 불필요함.
- 현재 HTML은 6,037,209바이트이며 SHA-256은 `030D3599A91CB78E532D5AE294810EC1D424AD783A91D4E36D22679DD95ABC63`임.
- 실제 게임 입력이나 장면 진행을 구현한 파일과 구분함. 무대와 대사는 정지 이미지로 유지하고 오른쪽 안내 영역만 움직임.
- `유저 인형 팔 보정.png`는 HTML 제작용 보정 원본임. 별도로 전달할 필요 없으며 이 전체 그림을 배경 정본으로 사용하지 않음.

# 2 입력과 정본

- 입력은 [소품 건네기 안내 대사창 유지.png](<../스토리보드/행동 안내 예시/소품 건네기 안내 대사창 유지.png>) 1개임. 1,671 × 941 px PNG이며 SHA-256은 `D25499C3D0A64DB9EBABBDACB981921F67E9644DFB3F97E9D40AC40D20E008CE`임.
- 기존 화면을 단일 이미지로 사용하라는 사용자의 현재 명시적 지시에 따라 동일 산출물 영역의 지정 이미지를 표시용으로 포함함. 해당 그림을 새로운 기획 근거로 채택한 것이 아님.
- 원본 배경의 PNG와 화면 배치를 유지하고 유저 인형의 해당 팔과 물그릇 및 구조 인형의 같은 팔 부분만 별도 이미지로 겹쳐 표시함. 이전 이미지 시안의 대사창 크기 근사 오차를 새로 수정하거나 픽셀 단위 원본 일치를 확인한 작업은 아님.
- 편집 정본은 [시안 템플릿.html](<../../../90_작업 공간/꼭두각시 행동 안내 HTML/시안 템플릿.html>)임. [빌드.cjs](<../../../90_작업 공간/꼭두각시 행동 안내 HTML/빌드.cjs>)가 지정 PNG를 데이터로 포함해 전달용 HTML을 생성함. 이후 재출력 전 전달용 파일의 사용자 직접 수정 여부 확인 필요함.

# 3 재생 동작

- 같은 안내 영역에서 제목과 동작 그림만 교체함. 설명 문장은 표시하지 않음.
- 건네기: 손이 소품 아래를 받친 채 왼쪽 원형 이펙트까지 수평으로 함께 이동함. 손과 소품을 같은 그룹으로 이동시켜 높이와 간격을 유지함. 소품의 비행 잔상은 제거함. 도착 후 손과 소품이 함께 사라지고 오른쪽 출발 위치에서 다시 나타나 반복함.
- 던지기: 소품을 쥔 팔을 들어 올린 뒤 아래로 휘두름. 손을 펼치는 순간 소품이 손에서 떨어져 별도 궤적으로 날아감. 초기 자세와 손에 소품이 있는 상태로 돌아가 반복함.
- 시안용 재생 주기: 동작당 3초, 같은 행동 2회 반복 후 전환함. 건네기 6초와 던지기 6초를 합친 12초 주기로 계속 재생함. 사용자가 확정한 게임 운영 수치와 구분함.
- 화면 크기가 달라지면 정지 화면과 안내를 같은 비율로 함께 축소함. 대사창을 재배치하거나 줄여 안내 공간을 만들지 않음.

# 4 검증 결과와 한계

## 4.1 실행 검증

- [브라우저 검증.cjs](<../../../90_작업 공간/꼭두각시 행동 안내 HTML/브라우저 검증.cjs>)로 Edge `156.0.4314.58`에서 실행함. 전달용 HTML 하나만 별도 임시 폴더에 복사한 뒤 브라우저 네트워크를 오프라인으로 설정해 파일 주소로 열었음.
- 배경 이미지 1개의 내장과 자동 시작, 건네기의 오른쪽에서 왼쪽 이동, 던지기의 팔 올림과 휘두름 및 손에서 소품 이탈을 시간 경과에 따라 확인함. 후속 수정에서는 건네기 전후의 손과 소품의 수평 변위 일치 및 높이와 간격 유지를 추가 검사함.
- 건네기에서 던지기로 전환한 뒤 다시 건네기로 돌아오는 전체 주기를 확인함. 전환 전후 대사창과 안내 영역의 화면 좌표가 동일함.
- 데스크톱 1,600 × 900, 세로 390 × 844 및 가로 844 × 390 화면에서 전체 화면 수용, 가로 넘침 없음과 대사창 및 안내 영역 사이 간격 유지 확인함.
- 실행 중 JavaScript 예외와 외부 네트워크 요청 없음. 지정 영역에는 제목 1개만 표시됨.
- 실행 결과는 [브라우저 검증.json](<../../../90_작업 공간/꼭두각시 행동 안내 HTML/브라우저 검증.json>)에 기록함.

## 4.2 시각 대조

- [건네기 검증.png](<../../../90_작업 공간/꼭두각시 행동 안내 HTML/건네기 검증.png>), [던지기 준비 검증.png](<../../../90_작업 공간/꼭두각시 행동 안내 HTML/던지기 준비 검증.png>)와 [던지기 검증.png](<../../../90_작업 공간/꼭두각시 행동 안내 HTML/던지기 검증.png>)를 직접 열어 확인함.
- 원래 그림의 안내 내용을 불투명한 같은 위치의 안내판으로 덮고 제목과 벡터 소품 및 팔을 재생함. 대사창과 무대 얼굴 및 구조 인형을 가리지 않음.
- 팔을 올린 상태의 손에 소품이 있고, 휘두른 뒤에는 손이 비고 소품이 떨어져 이동하는 모습을 확인함.
- 2026-11-04 손 동반 수정 후 갱신한 건네기 검증 화면을 직접 열어 손이 수평 자세로 소품 아래를 받치며 따라오는 모습과 안내 영역 안의 배치를 확인함.

## 4.3 미확인 범위

- 사람들에게 실제로 보여준 이해도, 선호하는 주기와 시선 이동 및 게임 내 모션 입력과 충돌 판정은 검증하지 않음.
- 다른 브라우저와 운영체제에서의 실행은 미검증임. 카메라 입력, 음성 및 실제 무대 동작은 포함하지 않음.
- 현재 파일은 사용자 검토 전 review 상태임.

# 5 유저 인형 팔과 물그릇 부착 보정

- 사용자 지시에 따라 전경 유저 인형의 해당 팔을 곧은 단일 구간으로 펴고 물그릇을 손끝에 부착함. 구조 인형의 같은 팔도 곧게 표현함.
- 내장 image_gen으로 제작한 [보정 원본](<유저 인형 팔 보정.png>)에서 필요한 부위만 원래 배경 위에 겹쳐 표시함. 입력과 실제 프롬프트 및 전사와 검수는 [유저 인형 팔 보정 기록](<유저 인형 팔 보정 기록.md>)에 관리함.
- 안내 script 본문의 SHA-256이 수정 전후 모두 `279e1c5b17d4566187354ef0541274ae8db06dce7788366f936002d2a6c142a4`로 일치함. 기존 안내 동작과 주기 및 대사창 배치를 유지함.
- 최종 브라우저 화면에서 기존 굽힌 팔의 흔적이 없고 손끝에 물그릇이 붙은 것을 직접 확인함. 실제 동작 연동의 리깅 구현은 요청 범위에 포함하지 않음.
