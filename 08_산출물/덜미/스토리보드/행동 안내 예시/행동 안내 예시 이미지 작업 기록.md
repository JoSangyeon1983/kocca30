# 1 용도와 입력

- 사용자 지정 [스토리보드 화면](<../2_2.png>)의 구도와 인형 외형을 참고한 소품 건네기 및 소품 던지기 안내 화면 검토용 이미지임.
- [덜미 - 나만의 꼭두각시 기획서: 동작 연동](<../../../../04_상세 기획/덜미 - 나만의 꼭두각시/덜미 - 나만의 꼭두각시 기획서.md#424-동작-연동>)의 동작을 표시하는 시각 제안임. 안내 효과와 인식 성능은 미검증이며 기획서 반영이나 승인으로 취급하지 않음.
- 동일 번호 폴더의 참조 이미지는 사용자의 현재 명시적 지정에 따라 구도와 외형의 시각 참조로만 사용함.
- 원본 스토리보드는 보존하고 별도 예시 PNG 2개로 생성함. 현재 사용본과 검수 범위는 아래 기록에 구분함.

# 2 생성 요청

- 도구: 내장 image_gen임. 실제 모델명은 반환되지 않아 미확인임. 출력 규격은 4.1절에 기록함.
- 화면비 요청: 참조와 같은 16:9임. 투명 배경은 사용하지 않음.
- 건네기: 세 인형 각각의 체간 중앙에 같은 크기와 밝기의 작은 원형 이펙트 하나씩 표시함. 특정 대상 연결선과 넓은 체간 강조를 제거함.
- 던지기: 화면 우측 상단의 고정 안내 칸에 팔 올리기와 내리기의 시범을 배치함. 움직이는 유저 인형에 붙은 동작 안내는 제거함.

## 4.4 검증 범위와 한계

- 2차 PNG 전체 디코딩, 규격과 SHA-256을 확인하고 아래 파일 정보와 전사 결과를 갱신함. 1차의 문자와 파일 검증 통과를 수정안의 검증과 구분함.
- 2차 이미지 통합 기록 검증 도구 통과함. 현재 이미지 2개, 지정 문자열 11개, 프롬프트 4개, 로컬 링크 6개와 삽입 대상 및 미채택 보관본 2개를 대조함. 생성 출력과 위키 반영본의 SHA-256 일치 및 헤더 번호와 계층 및 인식 가능한 링크 확인함.
- 이 통합 기록 자체에서 2장을 표시하므로 자기 문서에 대한 `article_sha256` 스냅샷 비교는 적용하지 않음. 전용 도구의 `article_matches_snapshot: false`는 이 미적용 상태임.
- 작은 원의 위치를 검수했으며 실제 충돌 판정 범위를 검증한 결과가 아님. 원형 상태 표시의 진행, 실행 중 안내 칸의 고정 여부, 유저의 동작 이해도와 인식 성능 및 쿨타임 수치는 미검증임.
- 기획서와 원본 스토리보드는 보존함. 본 이미지는 사용자 채택 전 검토안임.
- 후속 사용자 검토에서 던지기 2차는 소품을 계속 들고 있는 정지 시범으로 팔 휘두르기와 소품 비행을 전달하지 못하고, 고정 안내 칸이 구조 인형의 자리를 침범하는 문제로 미채택됨. 문자와 파일 검수 통과는 안내 설계의 승인과 구분함. 별도 시범 인형 배치 제안은 철회했으며 후속 이미지 생성은 수행하지 않음.
