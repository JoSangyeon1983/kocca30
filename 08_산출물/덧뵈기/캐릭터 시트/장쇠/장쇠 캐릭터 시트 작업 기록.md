# 4 제작과 검수

## 4.1 경로와 수정 이력

- 내장 image_gen으로 정면, 좌측면, 우측면과 후면 첫 생성, 후면 채 수정 및 전체 시트 합성 생성, 총 6회 실행함. 모든 호출에 transparent_background: true 전달함. 실제 모델명은 반환에서 확인되지 않음.
- 좌우 측면은 해당 원형 사진과 같은 정면 기준으로 독립 생성함. 반전본을 사용하지 않음. 전체 시트는 네 개별 PNG를 입력하여 도구가 다시 렌더링한 합성 생성본임. 개별 PNG와 시트 내부의 픽셀 동일성을 주장하지 않음.
- 후면 첫 생성에서 오른손까지 둥근 머리 채로 표현되어 오른손을 가는 채로 수정함. 수정 후 왼손의 둥근 머리 채와 오른손의 가는 채 및 후면 얼굴 부재를 직접 확인함.
- 수정 전 원본 1개는 보관 ID `2026-10-19 장쇠 후면 채 수정`으로 보존함. 보관 경로 문자열은 `99_보관소/종료 작업/2026-10-19 장쇠 후면 채 수정`임. 보관본은 현재 전달본으로 사용하지 않음.
- 전달 PNG의 크기 변경, 인체 변형과 배경 제거 후처리는 수행하지 않음. 현재 생성 출력과 복사본의 SHA-256 일치를 확인함.

## 4.2 직접 대조와 파일 확인

- 분홍 탈과 수염, 흰 복식, 상모와 장구 및 붉은 띠를 원형 이미지와 직접 대조함. 네 방향과 측면의 코 방향, 후면의 얼굴 부재 및 앞에 멘 장구의 몸통 가림을 확인함.
- 오른손 가는 채와 왼손 둥근 머리 채가 후면에서 화면 좌우가 바뀌어 보이는 점을 대조함. 세부 끈의 개수와 손가락 및 상모 부속 구조의 완전한 정확성은 미확인임.
- 문자 없는 캐릭터 시트이며 생성된 라벨과 판독 가능한 텍스트는 없음. 정보그래픽 라벨의 블라인드 전사는 적용하지 않음. 기대 텍스트 수량은 0임.
- PNG 5개를 다시 열어 실제 치수와 RGBA 모드, 파일 크기와 해시를 대조함. 알파 범위 0부터 255 및 네 모서리의 알파 0을 확인함.
- 투명 화면만으로 외곽을 판단하기 어려워 전체 시트를 밝고 어두운 바탕의 임시 검수 화면에서 직접 확인함. 해당 화면은 tmp에만 두고 전달 파일에 포함하지 않음.

## 4.3 한계와 사용자 검토 범위

- 탈의 미세 선과 눈 가장자리, 상모 기울기와 부속 막대의 길이, 장구 끈과 매듭 및 옷 주름에는 원형과 방향별 생성물 사이 차이가 남음. 실제 치수의 고증이나 엄밀한 3차원 정투영 도면으로 검증한 결과가 아님.
- 전체 시트는 개별 PNG보다 각 인물의 표시 해상도가 낮음. 세부 제작 확인에는 개별 PNG를 함께 사용함. 미세 외곽 픽셀과 낮은 알파 영역의 완전한 제거는 검증하지 않음.
- 정면과 전체 시트의 명시적 사용자 승인은 별도 확인 대상임. 자체 문서의 해시 순환 비교를 내용의 입증 근거로 사용하지 않음.
