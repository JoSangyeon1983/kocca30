# 2 현재 이미지와 제작 방법

- 개별 4장 모두 1086 × 1448 RGBA PNG임. 전체 시트는 4504 × 1618 RGBA PNG임.
- 입력 1은 사용자 승인 정면 개선안, 입력 2와 3은 사용자 제공 기본 정보와 상세 정보 이미지임. 후자의 대응 착용 사진을 복식 구조 대조에 사용함.

- 내장 image_gen 사용, transparent_background: true. 실제 모델명은 반환에서 확인되지 않음.
- Pillow는 네 이미지 배치와 방향 글자 추가에만 사용함. 크기 변경과 인체 변형, 좌우 반전 없음. 원본 RGBA 픽셀 그대로 복사함.

# 3 검수 결과와 한계

- 네 방향의 전신, 빈손, 상모와 신발 및 후면의 얼굴 미노출을 직접 확인함. 큰 주름과 길어진 체형의 시각적 연속성 확인함.
- 시트를 저장 후 다시 열어 정면, 좌측면, 우측면, 후면의 순서와 글자 각 1회 표시를 직접 확인함. 방향 글자는 생성하지 않고 맑은 고딕으로 합성함.
- 개별 생성 이미지에는 지정 라벨이 없음. 정보그래픽이 아니므로 생성 라벨 블라인드 전사는 적용하지 않음.
- 복사 전후 SHA-256 일치와 시트 내 개별 RGBA 픽셀 일치를 코드로 검사함. 알파 16 이상 가시 영역의 신발 기준선은 y=1488임.
- 손끝과 허리선, 모자 기울기와 천의 접힘에 방향별 차이가 남음. 엄밀한 3차원 모델용 정투영 도면으로 검증한 결과가 아님.
- 낮은 알파의 미세 외곽 픽셀과 세부 복식 정확성은 완전 검증하지 않음. 정면의 목 노출과 탈 세부 변화는 승인된 개선안을 유지함.
