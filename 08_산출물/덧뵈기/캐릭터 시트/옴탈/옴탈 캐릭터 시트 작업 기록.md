- 현재 시트의 왼쪽부터 정면, 화면 왼쪽을 향하는 좌측면, 화면 오른쪽을 향하는 우측면과 후면 순서임. 이미지 내부의 방향 글자는 생략하고 본 기록에서 순서를 표시함.
- 현재 파일은 모두 생성 도구가 반환한 PNG를 그대로 복사한 전달본임. 새 출력 전 사용자 직접 수정 여부와 현재 전달본의 정본 여부를 확인함.

# 4 제작 방법과 검수

## 4.1 생성 경로와 설정

- 내장 image_gen으로 정면 1회, 좌측면 1회, 우측면 1회, 후면 1회와 전체 시트 합성 생성 1회, 총 5회 실행함. 모든 호출에 transparent_background: true 전달함. 실제 모델명은 반환에서 확인되지 않음.
- 개별 방향은 세로 3:4 구도와 같은 비례를 요청함. 좌측면과 우측면은 원형 자료의 해당 방향을 각각 입력하여 독립 생성함. 반전본을 사용하지 않음.
- 전체 시트는 개별 이미지 4개를 재참조한 내장 도구의 합성 생성본임. 네 방향을 배치하는 과정에서 도구가 형태와 크기를 다시 렌더링하므로 개별 PNG와 시트 내부의 픽셀 동일성을 주장하지 않음.
- 이미지의 크기 변경, 인체 변형과 배경 제거 후처리는 수행하지 않음. 원본 PNG의 실제 알파를 보존하여 복사함.

## 4.2 직접 확인과 파일 대조

- 원형 자료와 생성물에서 붉은 탈, 짚모자, 검은 복식과 긴 소매, 붉은 허리띠와 흰 바지 및 짚신의 조합을 직접 확인함.
- 네 방향의 전신과 배치 순서, 측면의 코 방향, 후면의 얼굴 부재와 뒤쪽 붉은 매듭 위치를 직접 확인함. 생성 라벨이나 판독 가능한 글자는 없음.
- 정보그래픽이 아닌 문자 없는 캐릭터 이미지이므로 지정 라벨 목록과 블라인드 전사는 적용하지 않음. 이미지 내부 텍스트의 기대 수량은 0임.
- PNG 5개의 열기, RGBA 모드, 실제 치수, 파일 크기와 SHA-256 및 생성 출력과 복사본의 바이트 일치를 대조함. 알파 범위는 0부터 255이고 네 모서리의 알파는 모두 0임.
- 투명 화면만으로 외곽을 판단하기 어려워 임시 검수 화면에서 전체 시트를 밝은 바탕과 어두운 바탕에 표시하여 직접 확인함. 검수용 합성 화면은 tmp에만 두고 전달 이미지에 포함하지 않음.

## 4.3 한계와 미확인 사항

- 탈 돌기의 정확한 수와 배치, 목 노출, 모자 기울기, 소매 주름과 허리띠 천의 겹침에는 원형 자료 및 방향별 생성물 사이 차이가 있음. 세부 복식의 완전한 고증이나 엄밀한 3차원 정투영 도면으로 검증한 결과가 아님.
- 전체 시트는 개별 PNG보다 각 인물의 표시 해상도가 낮음. 후속 제작의 세부 확인에는 개별 PNG를 함께 사용함.
- 낮은 알파의 미세 외곽 픽셀과 미세 색 테두리의 완전한 제거는 검증하지 않음. 정면과 전체 시트의 사용자 승인은 별도 확인 대상임.
