# 1 용도와 현재 파일

- 사용자 2026-10-21의 첫 페이지 및 나머지 페이지 생성 요청에 따라 [옴탈잡이 만화 작업](<../../../90_작업 공간/스토리보드/옴탈잡이 만화 작업.md>)을 8페이지로 시각화한 검토용 산출물임.
- 현재 P07은 옴탈이 왼쪽으로 물러나고 꺽쇠가 남는 시도 2이며 P08은 꺽쇠가 악사와 문답한 뒤 같은 왼쪽으로 따라가는 시도 3임. 총 46컷과 말풍선 54개임. 실제 반환 PNG를 크기 변경이나 글자 합성 없이 저장함. [작업 문서의 생성 결과](<../../../90_작업 공간/스토리보드/옴탈잡이 만화 작업.md#73-생성-기록>)에서 순서대로 볼 수 있음.

# 2 정본과 입력 범위

- 컷과 대사의 편집 정본은 작업 문서이며 PNG는 해당 작업안의 파생 출력임. 작업 문서의 승인 상태를 높이지 않음.
- 대사와 지문 입력은 [문진수본 - 옴탈잡이: 현대어 풀이](<../../../05_참고 자료/연희본 현대어 풀이/문진수본 - 옴탈잡이.md#5-현대어-풀이>) 전체와 작업 문서 5절의 페이지별 배정임.
- 최초 변환 기준 시점은 2026-10-21임. P01은 참조 3개, 최초 P02~P08은 같은 3개에 P01 PNG를 화풍 참조로 추가함. 현재 P07과 P08은 사용자 수정한 현대어 풀이 312~330행과 수정 콘티를 적용함. P07은 수정 전 페이지와 K, O 이미지, P08은 수정 전 페이지와 K 이미지 및 이전 P07의 화풍을 첨부함. 입력 역할과 실제 지시문은 9절에 기록함.

# 3 생성 경로와 수정 이력

- 내장 image_gen으로 이미지별 개별 호출함. referenced_image_paths로 참조 첨부, transparent_background: false임. 모델과 해상도 및 품질의 별도 설정 인자는 전달하지 않음. 실제 모델명은 반환에서 미확인임.
- 최초 8페이지 생성까지 누적 15회임. 사용자 원문 수정으로 P07 1회와 P08 2회를 추가 호출하여 현재 누적 18회임.
- 최초 문자와 꼬리 수정에는 직전 해당 페이지 PNG만 첨부함. 이번 주체 변경에는 위 입력 범위의 캐릭터 참조를 추가함. 최초 실제 지시문은 7절, 이번 수정 지시문은 9절에 원문 보존함.

# 4 전사와 문자열 대조

- 각 결과는 이미지 경로만 받은 별도 컨텍스트의 판독을 거쳤으며 정답 문구를 제공하지 않음. 현재 P07 시도 2와 P08 시도 3은 새 컨텍스트에서 재판독함. P08 시도 2도 독립 판독으로 C04와 C05의 방향 차이를 확인한 뒤 수정함. P01~P06의 시각 검수는 최초 생성 검수를 재사용함.
- 행바꿈을 공백으로 이어 철자, 문장부호, 위치와 횟수를 대조함. 아래는 최종 대조용 전사임. P06 그래, 옴!은 서로 다른 두 컷에서 2회이며 나머지는 각 배정 위치에서 1회임.
- 판독 오독은 확대에서 재확인함. P03 이전 전사의 났다·났겠다와 달리 실제 글자는 나겠다였음. P04 시도 2의 쏙 전사는 쑥으로 확인함. P04 판독 정정은 구조화 기록에도 원시 판독을 함께 남김.
- P03 시도 4 전사의 사람이나·짐승이나는 확대에서 실제 오류로 확인하여 수정함. 시도 5의 독립 전사 10개는 지정 문자열과 모두 일치함. 이전 시도 3의 널어놓은 전사는 확대에서 넣어놓은으로 확인하여 통과시키지 않음.
- 최종 PNG에서 지정 외 읽히는 문자와 로고를 발견하지 않음. 기계 대조는 기록된 문자열과 횟수 및 파일 일치를 검증하는 범위임.

- P07 시도 2: 무대사 4컷과 2명, 2명, 2명, 1명의 구성 확인함. C03에서 옴탈이 왼쪽으로 물러나고 C04에서 밝은 탈과 흰옷의 꺽쇠가 오른쪽에 홀로 남음.
