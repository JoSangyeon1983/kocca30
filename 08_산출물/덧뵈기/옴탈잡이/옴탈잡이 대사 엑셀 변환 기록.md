# 1 용도와 파일

- [옴탈잡이 대사.xlsx](<옴탈잡이 대사.xlsx>): 옴탈잡이 극 진행 데이터에서 대사만 추출한 사용 및 전달용 XLSX임.
- 시트 `대사`에 `speaker`, `text` 두 열과 데이터 35행으로 구성함. 헤더를 포함한 범위는 `A1:B36`임.
- 현재 파일 크기는 6,759바이트이며 실제 파일 배치 완료함.

# 2 정본과 입력 범위

- 내용 정본은 사용자 지정 [극 진행 데이터.js](<../../../90_작업 공간/스토리보드/옴탈잡이/극 진행 데이터.js>)이며 XLSX는 해당 데이터의 파생 출력임.
- 사용자가 지정한 작업 공간 파일을 이번 필드 추출 범위의 입력으로 사용함. 원본의 검토 및 승인 상태를 변경하거나 기획 근거로 채택한 작업이 아님.
- 변환 기준은 2026-10-23 17:39 한국 표준시의 입력 파일임. SHA-256은 `15e232456e144cc901d780c5c274a1b2609e411b3047561a24717795f3367fe8`임.
- `events` 전체 65개 중 `kind === "speech"`인 35개에서 `speaker`, `text`만 추출함. 첫 대사는 `event-001`, 마지막 대사는 `event-063`임.

# 3 변환 방법

- 자바스크립트를 실행하지 않고 `window.PLAY_DATA`에 할당된 JSON 객체를 파싱함.
- 배열의 원래 순서와 화자, 대사 문자열을 유지함. 교정, 요약, 병합과 중복 제거는 수행하지 않음.
- 대사가 아닌 이벤트 30개는 제외하고 장면, 동작과 기타 필드는 출력하지 않음.
- 두 열을 텍스트로 저장하고 필터, 첫 행 고정과 대사 줄바꿈을 설정함.

# 4 검토 결과와 현재 상태

- 전체 대사 35행, 데이터 셀 70개의 원본 일치 확인함. 화자별 개수는 꺽쇠 18개, 옴탈 12개, 장쇠 5개임.
- XLSX 내보내기 후 Artifact Tool로 재열람하여 헤더와 전체 셀 값을 추출 데이터와 대조함. 오류 검색 결과 0건임.
- 처음, 최장 대사와 마지막 구간의 PNG를 직접 확인함. 한글 표시, 긴 대사의 줄바꿈과 셀 내부 표시 확인함.
