# 1 용도와 정본

- 용도: 현재 번역 JSON의 키, 한국어와 영어를 엑셀 표로 비교하고 검토하거나 전달하기 위한 XLSX임.
- 정본: [localization.json](<../../90_작업 공간/번역 검수/localization.json>)과 [character_name_pool.json](<../../90_작업 공간/번역 검수/character_name_pool.json>)임. XLSX는 두 JSON의 파생 출력이며 엑셀에서 고친 내용은 JSON에 자동 반영되지 않음.
- 입력 범위와 권한: 사용자가 현재 JSON을 엑셀 표로 변환하도록 지정한 범위만 사용함. 작업 공간 입력의 서식 변환이며 기획 근거 채택이나 문서 승인으로 취급하지 않음.
- 변환 기준 시점: 2026-11-10 12:20:01 KST(Korea Standard Time, 한국 표준시)임.

# 2 변환 기준

| 시트 | 입력 파일 | 데이터 행 | 표 범위 | 데이터 범위 |
|---|---|---:|---|---|
| UI 문구 | localization.json | 183행 | `A6:C189` | `A7:C189` |
| 이름 풀 | character_name_pool.json | 20행 | `A6:C26` | `A7:C26` |

- 두 시트 모두 `키`, `한국어 (ko)`, `영어 (en)`의 세 열로 구성함. 원본 키 순서와 문자열을 그대로 유지함.
- `{0}`, `{1}`, `{2}`와 아포스트로피 및 줄바꿈 의도의 다중 공백을 보존함. 이름 풀의 `0`부터 `19`까지인 키도 문자열로 저장함.
- 시트별 표 필터와 위쪽 6행 및 왼쪽 1열 고정을 적용함. 고정 뒤 시작 셀은 `B7`임.
- 긴 문구는 원문에 개행을 추가하지 않고 셀의 자동 줄바꿈과 행 높이로 표시함. 계산 수식과 추가 번역은 넣지 않음.
