# 1 목적

- 사람이 막대를 움직이고, 그 움직임이 위의 쳇바퀴에 전달되어 균형을 유지하며 회전하는 기본 시뮬레이션 구축임.
- 기본 돌리기가 작동한 뒤 버나 사위의 적용 가능성과 동작 모습을 검토함.

# 2 첫 검토 범위

- HTML에서 사용자 제안 키보드안을 우선 시범 적용함. 마우스 드래그와 화면 버튼도 제공하며, 최종 입력 수단은 체험 검토 후 정함.
- 쳇바퀴가 이미 회전하는 초기 상태에서 회전을 유지하는 과정부터 확인함.
- 막대기 움직임, 접촉에 따른 쳇바퀴 반응과 균형 유지에 집중함.
- 사용자 지시에 따라 Space로 던질사위를 실행하는 입력 추가함. 공중 회전, 재접촉과 다시 받지 못한 경우의 낙하 검토함.

# 3 조작안

- 사용자 조작 대상은 막대의 위치, 좌우 기울기와 막대를 움직이는 속도임. W는 빠르게, S는 느리게 움직이는 입력임.
- 손으로 막대를 움직이는 운동을 입력으로 두고, 막대와 쳇바퀴의 접촉에 따른 반응을 물리 계산으로 구현함. 구체적인 운동 궤적과 접촉 모델은 작성자가 구현 가정으로 설정하고 기록함.

| 조작 | 움직임의 의미 | 확인할 반응 |
|---|---|---|
| 막대 위치 이동 | 막대를 쥔 손의 위치를 좌우로 이동 | 지지 위치 변화에 따른 쳇바퀴의 이동과 흔들림 |
| 막대 좌우 기울기 조절 | 막대가 향하는 방향을 좌우로 조정 | 쳇바퀴의 자세 변화와 지지 유지 |
| 막대를 움직이는 속도 조절 | W로 손의 막대 움직임을 빠르게, S로 느리게 변경 | 막대 움직임의 속도 변화에 따른 쳇바퀴의 회전과 균형 변화 |
| 던질사위 | Space로 던지기 힘과 받는 지점으로 움직이는 손동작 실행 | 공중 궤적과 회전, 다시 받기 또는 낙하 |

- 키보드안은 좌우 방향키로 위치, A와 D로 기울기, W와 S로 막대를 움직이는 속도를 조절하는 사용자 제안임. 시범 구현에 적용하며 마우스안과의 최종 선택은 미정임.
- 회전 방향 선택이나 막대기 축에 지속 회전 동력을 주는 조작은 포함하지 않음.

# 4 확인할 결과

- 입력한 막대 운동에 따른 쳇바퀴의 위치, 각도와 회전 변화를 관찰함.
- 막대의 위치, 기울기와 움직임의 속도를 바꾸며 회전 유지, 흔들림과 낙하가 발생하는 조건을 탐색함.
- 회전 유지 범위와 낙하 조건은 사전에 지정하지 않고 시뮬레이션 결과로 확인함.
- 던질사위부터 적용하고 동작 모습을 검토함. 다른 사위는 이후 사용자 지시에 따라 추가 검토함.

# 5 다음 검토 사항

## 5.1 기구 구조와 균형

- 기구 구조: [남사당놀이 - 버나: 사용 기구](남사당놀이%20-%20버나.md#2-사용-기구)의 약 10cm 두께 쳇바퀴, 양면의 여러 겹 헝겊과 중앙의 지름 약 15cm 가죽을 바탕으로 외형, 접촉 및 질량 분포 재검토함. 테두리 높이와 국소 변형은 구조 해석이며 실제 물성은 미확인임.
- 2026-10-08 구조 반영: 높이 10cm 테두리, 평평한 양면의 헝겊과 지름 15cm 중앙 가죽으로 재생성함. 고정된 오목한 홈을 제거하고 평면 접촉과 재료별 질량을 나눈 관성 계산 적용함. 상세 내용은 [버나잡이 한 판: 버나 구조와 시뮬레이션 영향](../프로토타입_버나잡이%20한%20판/버나잡이%20한%20판.md#23-버나-구조와-시뮬레이션-영향)에 기록함.
- 구조 변경 후 검토: 기본 회전과 입력 반응, 낙하 및 던질사위의 재접촉 확인함. 기본 설정은 약 1.22초 뒤 바닥 도달하므로 기존 손동작과 평면 접촉만으로 장시간 균형이 확보되지 않음. 실제 손의 균형 보정, 천과 가죽의 변형 및 물성, 긴 구간의 수치 수렴은 추가 검토 필요함. 실제 실행 결과는 [버나잡이 한 판: 검토 결과](../프로토타입_버나잡이%20한%20판/버나잡이%20한%20판.md#4-검토-결과)에 기록함.
