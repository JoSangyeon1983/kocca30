# 1 자료 개요

- 버나처럼 막대 위에서 사물을 돌리는 기예와 관련된 디지털 콘텐츠 4건, 국내 실물 체험 프로그램 2건 정리.
- 가상현실(VR, Virtual Reality)의 접시 돌리기, 카메라 동작 인식, 키 입력 게임과 실물 도구 체험을 구분함. 사례별 근거는 아래 각 사례의 원자료 링크에 표시함.
- 버나 체험 콘텐츠를 기획하는 독자가 조작 방식과 게임 규칙을 비교하기 위한 참고 자료. 접시 돌리기 게임의 규칙을 실제 버나의 물리 법칙이나 전승 동작으로 확정하는 자료는 아님.

# 2 출처와 작성 방식

- 외부 자료: 게임 개발자의 배포 페이지, 접시와 막대 자료 제작자의 설명, EyeToy: Play 사용 설명서, 서울시 보도자료와 경기도뉴스포털의 현장 기사.
- 작성 방식: 대규모 언어 모델(LLM, Large Language Model)을 통한 원자료 요약과 비교 정리. 사례의 존재와 기능은 연결된 외부 자료를 근거로 기록함.
- 확인일: 2026-10-08. 원자료의 공개 설명과 매뉴얼을 대조한 범위이며, 게임 실행, VRChat 월드 접속과 현장 참여는 수행하지 않음.
- 기획 참고사항은 작성자의 해석으로 분리함. 운영 일정, 신청 가능 여부와 기기 호환성의 한계는 해당 사례에 표시함.

### 3.1.1 Hattrick The Magician

- 체험 내용: 마술 게임의 기예 목록에 접시 돌리기인 Plate Spinning 포함. 컨트롤러의 그립 버튼으로 물건을 잡고 트리거 버튼으로 상호작용하는 조작 안내 제공함.
- 배포 정보: 개발자 페이지에 Released 상태, Android 플랫폼과 VR 태그 표시. `Hattrick_The_Magician.apk` 파일과 Oculus Quest 2 설치 안내 링크 제공함.
- 확인 한계: 접시 돌리기의 세부 손목 동작, 막대와 접시의 접촉 처리, 최신 Quest 기기 호환성은 미확인임.
- 근거 위치: [개발자 배포 페이지](https://sadeemboji.itch.io/hattrick)의 How to Play, Controls, Download, Install instructions. 페이지에 연결된 [Plate Spinning 튜토리얼](https://youtu.be/4ezHYKoRZMg)은 후속 확인용 링크이며 영상 내용은 미대조임.

### 3.1.2 Juggling Practice Room과 접시 돌리기 Unity 자료

- 체험 안내: ドクター・デリート의 배포 페이지에서 VRChat의 Juggling Practice Room을 접시 돌리기가 가능한 월드로 소개함. 월드명 검색 방법을 제시하며, 현재 직접 접속 가능한지는 미확인임.
- 제작 자료: 접시와 막대의 3차원 모델, 물리 재질, 일반 재질과 스크립트를 포함한 Unity 패키지 배포. 접시에 충돌 처리와 회전을 쉽게 만드는 스크립트가 포함된다고 설명함.
- VR 적용 조건: 접시와 막대를 잡는 스크립트 등을 별도로 추가하면 VR에서 사용할 수 있다고 설명함. 배포 패키지를 완성된 VR 체험 프로그램으로 취급하지 않음.
- 이용 조건: 제작자 설명에 VRChat 사용과 스크립트 수정 허용, 자료의 재배포와 판매 금지 표시. 프로젝트 적용 시 원문 이용 조건 확인 필요함.
- 근거 위치: [皿回しの皿と棒〖UnityPackage〗 배포 페이지](https://booth.pm/ja/items/4020089)의 상품 설명. 월드 내부의 실제 조작 방식과 물리 동작은 미대조임.

### 3.1.3 EyeToy: Play의 Plate Spinner

- 체험 방식: PS2의 EyeToy USB 카메라를 사용하는 게임. 매뉴얼에 양손을 사용해 화면 속 막대 위 접시의 회전을 유지하도록 안내함.
- 성공과 실패: 회전이 너무 느리면 접시가 막대에서 떨어지고, 너무 빠르면 접시가 날아가는 규칙. 적정 회전 상태인 sweet spot을 시각 효과와 소리로 표시함.
- 추가 규칙: 최대 4개 접시를 모두 적정 회전 상태로 유지하면 보너스 점수 제공. 막대를 타고 올라오는 원숭이를 쳐서 떨어뜨리는 방해 요소 포함함.
- 기획 구분: 실물 막대의 조작을 측정하는 사례가 아니라 손 움직임으로 화면 속 접시의 회전을 유지하는 사례임. 과속 실패는 해당 게임의 규칙으로 기록함.
- 근거 위치: [EyeToy: Play 사용 설명서 사본](https://db.hfsplay.fr/files/2019/12/02/EyeToy_-_Play_USA_XomAEr4.pdf)의 EYE TOY USB CAMERA USAGE INSTRUCTIONS, 인쇄 쪽수 30의 PLATE SPINNER 및 TIPS FROM THE ORACLE.

### 3.1.4 Spinny Plate

- 체험 방식: 대응하는 키를 눌러 접시를 회전시키고, 키를 길게 눌렀다 놓으면 접시가 점프하는 조작 방식.
- 게임 목표: 접시가 과속으로 날아가지 않게 하면서 가능한 오래 회전을 유지함. 개발자 페이지에 낮은 회전 속도를 색으로 표시하는 수정 내용도 기록됨.
- 공개 정보: 개발자 mechabit의 페이지에 Released 상태, HTML5 플랫폼과 Run game 항목 표시. 개발 로그에 2020-07-19 수정 기록 존재함.
- 기획 구분: 신체 동작이나 실물 막대를 인식하는 체험보다 회전 유지와 점프를 게임 규칙으로 구성한 참고 사례임.
- 근거 위치: [개발자 배포 페이지](https://mechabit.itch.io/spinning-plates)의 Instructions, Post Jam Fix, More information, Development log.

# 5 확인 범위와 미확인 사항

- 외부 원자료의 설명과 운영 기록을 확인한 참고 문서임. `source_check: partial`은 공개 설명의 대조와 실제 체험 검증의 범위를 구분한 상태임.
- 게임의 실제 실행, APK 설치, Unity 패키지 내부 코드 검사와 VRChat 월드 접속은 미실시함. 기능 설명을 실행 검증 결과로 해석하지 않음.
- 국내 사례의 공지와 과거 체험 기록은 현재 참여 가능성을 보장하지 않음. 참가 시 해당 운영기관의 최신 안내 확인 필요함.
- 국내에서 센서 막대로 가상 버나의 회전과 균형을 조작하는 상용 체험의 운영 사례는 이번 검색 범위에서 확인하지 못함. 그러한 콘텐츠가 없다는 결론은 아님.
