# 1 목적

- 회전 중인 쳇바퀴를 막대 위에서 지지하고, 공중으로 던졌다가 다시 받는 던질사위를 검토하는 시뮬레이션임.
- 막대의 위치, 기울기와 움직임의 속도를 바꾸며 쳇바퀴의 위치, 각도, 회전과 낙하 조건을 검토함.

# 2 입력 근거와 구현 가정

## 2.1 기본 돌리기

- 구현 가정: 손의 위치와 막대 방향을 바꾸는 반복 함수는 작성자가 임의 설정한 계산 조건임. 실제 연희 동작과의 대응은 미검증임.
- 접촉 계산: 쳇바퀴를 독립된 강체로 두고 중력, 접촉 충격량, 마찰과 각운동량을 계산함. W와 S는 손동작의 주기를 변경함. 쳇바퀴 회전 속도를 직접 지정하는 동력은 없음.
- 현재 형상: 높이 10cm의 원형 테두리 양면에 평평한 헝겊과 지름 15cm의 중앙 가죽을 표시함. 중앙이 솟는 곡면과 고정된 오목한 홈 제거함. 자료의 설명과 구현 가정의 구분은 [버나잡이 한 판: 버나 구조와 시뮬레이션 영향](#23-버나-구조와-시뮬레이션-영향)에 기록함.
- 접촉 형상: 변형 전 아랫면을 평면으로 계산함. 가죽과 헝겊의 접촉 재료를 위치에 따라 구분하되, 미측정 상태이므로 마찰계수는 모두 0.20으로 설정함. 막대를 중앙에 자동으로 가두는 힘은 없음.

### 2.1.1 외형과 질량

| 구현 값 | 설정 |
|---|---|
| 쳇바퀴 질량, 반지름 | 0.32kg, 0.235m |
| 테두리 높이, 중앙 가죽 지름 | 0.10m, 0.15m. 기구 설명의 수치를 적용함 |
| 테두리 폭, 재료별 질량 비율 | 0.010m. 테두리 65%, 헝겊 25%, 가죽 10%의 구현 가정임 |

### 2.1.2 접촉과 운동 조건

| 구현 값 | 설정 |
|---|---|
| 막대 길이 | 0.50m |
| 초기 쳇바퀴 회전, 기울기 | 210rpm, 2.5도 |
| 초기 손동작 속도 | 초당 2.9회 |
| 양면 높이와 접촉면 | 윗면 `+0.05m`, 아랫면 `-0.05m`. 중심부터 가장자리까지 일정함 |
| 가죽, 헝겊 마찰계수와 계산 간격 | 각각 0.20, 1/360초 |

- 테두리 높이와 가죽 지름 외의 수치는 관찰 가능한 초기 구현을 위한 가정값임. 전체 반지름, 질량, 재료별 질량 비율과 물성의 실측값은 미확인임. 전체 설정은 [physics.js](physics.js)의 `DEFAULTS`에 기록함.

## 2.2 던질사위

- 동작 범위: [남사당놀이 - 버나: 버나돌리기](../../01_References/02_남사당놀이/남사당놀이%20-%20버나.md#32-버나돌리기)에서 설명한, 회전 중인 버나를 공중으로 던지고 다시 받아 돌리는 동작을 참조함. 해당 전사본의 원자료 대조는 미완료임.
- 던지기 입력: 막대 위에서 지지되는 경우 Space 한 번으로 위쪽 접촉 충격량 `질량 × 2.2m/s`, 기본값 0.704N s 적용함. 가로 충격량은 현재 이동과 마찰 한도에 따라 계산함. 손은 0.16초 동안 12cm 올린 뒤 0.30초 동안 복귀함. 모두 실측되지 않은 구현 가정임.
- 받기 입력: 예상 낙하지점으로 막대를 옮기는 손동작 보조를 포함함. 공중에서 사용자 위치와 기울기 입력으로 받는 지점을 변경할 수 있음. 지지 복귀는 실제 접촉 계산으로 결정하며, 쳇바퀴 위치와 회전을 강제로 복원하지 않음.
- 공중에서는 중력과 각운동량에 따라 이동 및 회전함. 공중 상태의 재던지기와 키를 계속 누를 때의 반복 실행은 차단함. 받지 못하면 바닥으로 떨어짐.

## 2.3 버나 구조와 시뮬레이션 영향

- 구조 반영 결과: 테두리, 양면의 헝겊과 중앙 가죽을 표시하고 평면 접촉으로 변경함. 임의의 중앙 홈을 제거하고 재료별 질량을 나눈 관성 계산 적용함. 실제 천과 가죽의 변형, 질량 분포와 손의 균형 보정은 미검증임.

### 2.3.1 기구 설명과 해석

- 자료의 설명: [남사당놀이 - 버나: 사용 기구](../../01_References/02_남사당놀이/남사당놀이%20-%20버나.md#2-사용-기구)의 버나 항목, 검토 당시 37번 줄임. 해당 문서는 원자료 미대조 전사본임.

> ① 버나 : 쳇바퀴를 두께 10센티 정도로 자르고 그 양면에 헝겊을 몇 겹 바르고, 원심에 직경 15센티 가량의 가죽을 둥글게 오려 붙였음

- 구조 해석: 원형 테두리 양면을 헝겊으로 덮고 중앙에 가죽을 덧댄 구조로 읽힘. 약 10cm는 테두리의 높이로 해석하며, 속이 찬 10cm 두께의 판을 뜻한다고 단정하지 않음. 아래 영향은 이 설명과 현재 코드의 대조에 따른 작성자의 해석임.

### 2.3.2 현재 구현과 수정 검토

| 기구 설명 | 현재 구현 | 남은 검토 |
|---|---|---|
| 쳇바퀴 테두리와 덮개 | 속이 빈 원형 테두리와 양면 덮개로 구분하고 재료별 질량과 위치로 관성 계산함 | 질량 비율과 테두리 폭은 임의 설정이며 실측 대조 필요함 |
| 약 10cm 두께 | 테두리 높이 10cm, 위아래 면의 높이 차 10cm로 표시함 | 해당 설명을 테두리 높이로 읽은 해석임. 대상 기구의 치수 대조 필요함 |
| 양면의 여러 겹 헝겊 | 평평한 양면과 직조 무늬, 가장자리의 얇은 겹선 표시함 | 평평한 무변형 면은 구현 가정임. 겹선 수는 설명용 표현이며 실제 겹수와 두께는 미확인임. 국소 변형과 충격 흡수는 미구현임 |
| 중앙의 지름 약 15cm 가죽 | 양면 중앙에 지름 15cm의 원형 가죽과 부착선 표시함. 가죽은 주변 헝겊과 같은 높이로 단순화함 | 가죽 두께와 부착 방식은 미확인임. 표시한 부착선은 설명용 표현임. 가죽과 헝겊 마찰계수는 구분 가능하나 현재 모두 미측정 가정값임 |

- 변경 이유: 이전 [physics.js](physics.js)의 고정된 홈을 [app.js](app.js)에서 양면에 함께 적용해 중앙이 솟는 오류 발생함. 천과 가죽의 변형 가능성은 고정된 홈의 근거가 아니므로 외형과 접촉 계산에서 함께 제거함.
- 재검증 결과: 평평한 양면, 테두리와 가죽 규격, 초기 회전과 접촉, 위치 및 기울기 입력, 낙하와 던진 뒤 재접촉 확인함. 기본 설정에서 약 1.22초 후 바닥 도달하므로 장시간 균형 유지 조건은 확보되지 않음. 상세 결과는 [버나잡이 한 판: 검토 결과](#4-검토-결과)에 기록함.
- 미확인 값: 실제 질량과 재료별 질량 분포, 헝겊의 팽팽함, 가죽의 두께와 변형량, 접촉 재료별 마찰계수임. 약 10cm와 지름 약 15cm는 해당 자료의 기구 설명이며 시뮬레이션 대상 기구의 실측값은 아님.

# 3 실행 방법

- [버나잡이 한 판.html](버나잡이%20한%20판.html)을 Chrome 또는 Edge에서 열어 실행함. 외부 다운로드나 서버 없이 실행 가능한 단일 HTML임.
- 사용자 제안 키보드안을 우선 시범 적용함. 마우스와 화면 버튼도 조작 가능함.

| 입력 | 조작 |
|---|---|
| W, S | 손으로 막대를 움직이는 속도의 증가, 감소 |
| A, D | 막대의 좌우 기울기 |
| 좌우 방향키 | 손의 좌우 위치 |
| 화면 드래그 | 손의 좌우 위치 |
| Shift를 누른 채 드래그 | 막대의 좌우 기울기 |
| Space 또는 던질사위 버튼 | 던졌다가 받는 손동작 실행. 일시정지 상태에서는 재개 후 실행 |
| P 또는 일시정지 버튼 | 일시정지 또는 재개 |
| R | 초기 상태 복원 |

- 화면의 입체, 정면과 위 시점으로 자세 및 회전을 관찰함. 관찰 도구에서 궤적과 접촉 위치를 표시하고 최근 최대 30분의 기록을 CSV로 내려받을 수 있음. 던지기 및 받기 횟수, 공중 상태와 막대 끝 높이도 기록함.
- 소스 수정 후 재생성 및 검증 명령임. Node.js 22 이상과 설치된 Chrome 또는 Edge가 필요함.

```powershell
node "90_Workspace/프로토타입_버나잡이 한 판/build.cjs"
node "90_Workspace/프로토타입_버나잡이 한 판/verify.cjs" --browser
```

- 균형 가능성의 별도 계산 실험은 [balance-feasibility.cjs](balance-feasibility.cjs)로 실행함. Node.js 기본 모듈만 사용하며 브라우저 불필요함. 아래 순서로 실행하며, 같은 결과 파일에 기록하므로 동시 실행하지 않음. 실험의 막대 위치 제어는 현재 HTML에 반영되지 않음.

```powershell

node "90_Workspace/프로토타입_버나잡이 한 판/balance-feasibility.cjs" dynamic
```

# 4 검토 결과

## 4.1 형상과 물리 계산

- 형상 대조: 테두리 높이 10cm, 중앙 가죽 지름 15cm와 중심부터 가장자리까지 일정한 접촉면 높이 검사 통과함. 입체, 정면과 위 시점의 화면에서 중앙 돌출이 없는 양면과 가죽 표시 육안 확인함. 높이와 지름은 Reference의 기구 설명과 대조했으며 대상 기구 실측값은 아님.
- 기본 및 입력 변화 실행: 초기 0.5초 동안 지지와 회전 확인함. 60초 관찰에서 기본 설정은 약 1.22초에 처음 바닥 도달함. 손동작 중단은 약 1.17초, 위치 2cm 변경은 약 1.29초, 기울기 3도 변경은 약 1.20초, 초당 4회 입력은 약 1.26초에 바닥 도달함. 고정된 홈을 사용하던 이전 코드의 60초 지지 결과는 현재 모델에 적용 불가함.
- 던질사위 실행: 시작 후 0초, 0.1초, 0.2초, 0.4초와 0.6초에 던지는 5개 조건에서 약 22.9~25.3cm 상승과 공중 회전, 재접촉 확인함. 받기 판정 직후 약 199.9~207.6rpm 확인했으나, 모든 조건에서 시작 후 약 1.61~1.85초에 처음 바닥 도달함. 손을 42cm 옮긴 조건은 다시 받지 못하고 낙하함. 재접촉을 장시간 지지 유지로 해석하지 않음.
- 계산 검사: 비접촉 상태의 회전과 공중 궤적이 막대 입력과 독립적임. 유한 상태, 자세 정규화와 위치를 강제로 복원하지 않는 던지기 검사 통과함. 1/360초 및 1/720초 간격의 비교는 초기 0.5초에서 회전 차이 1rpm 미만과 기울기 차이 1도 미만 확인함. 1초 비교는 회전 차이 약 1.03rpm과 기울기 차이 약 5.81도로 두 기준 모두 미통과함. 긴 구간의 수치 수렴과 균형 유지 모델은 추가 검토 필요함.
- [물리 실행 결과](qa/physics-result.json)에 평면 형상 검사, 입력별 낙하 시각과 던질사위의 재접촉 및 이후 낙하 기록 저장함. 안정성 측정값은 구현 가정에 따른 계산 결과이며 실제 버나의 물리 조건으로 일반화할 수 없음.

## 4.2 브라우저 실행과 생성본

- Chrome에서 단일 HTML 직접 실행함. Space 던지기와 공중 회전, 재접촉, 스크롤 차단과 누른 채 유지할 때의 재실행 차단 확인함. 던질사위 버튼과 P 일시정지, 키보드, 드래그, 화면 버튼, 슬라이더 포커스, 재시작, 입력 해제, 터치와 CSV(Comma-Separated Values, 쉼표 구분값) 출력 검사 통과함.
- 너비 1360픽셀과 390픽셀에서 가로 넘침과 실행 오류 없음. [입체 화면](qa/perspective.png), [정면 화면](qa/front.png), [위 시점](qa/top.png), [공중 회전](qa/throw-flight.png)과 [모바일 화면](qa/mobile.png) 육안 확인함.
- [버나잡이 한 판.html](버나잡이%20한%20판.html) 재생성 완료함. [브라우저 실행 결과](qa/browser-result.json)에 적용한 테두리와 가죽 규격 및 조작 검사 기록함. `status: review`로 Workspace에 유지함. 자동 검사 통과는 실제 기구 재현이나 장시간 균형 유지의 검증 완료를 의미하지 않음.

## 4.3 입력에 따른 균형 유지 가능성

- 검토 결론: 현재 화면의 입력으로 안정적인 수동 균형 유지 조건은 확보되지 않음. 같은 접촉 계산에 독립적인 좌우 및 앞뒤 막대 위치 입력과 상태 기반 제어를 적용한 별도 실험에서는 30초 유지 확인함. 물리 계산 안에서 제어 가능한 조건이 존재함을 확인했으며, 현재 화면의 조작 가능성이나 실제 버나의 재현을 검증한 결과는 아님.
- 기록: [가능성 검증 코드](balance-feasibility.cjs)와 [가능성 실행 결과](qa/balance-feasibility.json)에 조건, 입력 궤적, 최초 바닥 도달 시각과 계산 간격별 결과 저장함. 프로젝트의 실행 검토 기록이며 정식 지식의 외부 근거로 사용하지 않음. 실제 실행용 물리 코드와 단일 HTML은 이 실험에서 수정하지 않음.

### 4.3.1 판단 기준과 이상 상태

- 기본 검토 구간은 30초임. 최초 바닥 접촉 없음, 접촉 시간 비율 95% 이상, 최대 기울기 20도 이하, 종료 회전 50rpm 이상과 모든 상태의 유한성을 관찰 기준으로 설정함. 실험자가 정한 판정 기준이며 실제 기구의 물리 한계값은 아님. 고정값 탐색과 초기 2축 탐색은 10초 구간으로 별도 기록함.
- 정확히 수평인 쳇바퀴를 중앙의 정지한 수직 막대로 받치는 상태는 30초 유지됨. 종료 회전 약 80.96rpm임. 초기 기울기 0도와 반복 손동작 제거가 필요한 이상 상태이며 현재 초기 상태 및 사용자 조작 범위의 성공 증거로 사용하지 않음.
- 같은 정지 막대 조건에서 초기 기울기만 2.5도로 변경하면 약 1.29초에 바닥 도달함. 이상적인 평형 상태의 존재와 기울어진 상태를 입력으로 보정하는 능력을 구분함.

### 4.3.2 현재 조작의 탐색 결과

- 현재 입력은 손의 좌우 위치 `-0.42~+0.42m`, 막대의 좌우 기울기 `-28~+28도`와 반복 손동작 속도 `0~5Hz`임. 앞뒤 위치는 반복 손동작의 위상에 종속되며 독립적인 앞뒤 입력은 없음. 속도 입력은 쳇바퀴 회전을 직접 설정하는 기능이 아님.
- 기본 초기 상태에서 위치 11개, 기울기 9개와 속도 11개의 고정값 조합 1,089개 실행함. 모두 10초 이전 바닥 도달함. 가장 긴 조건은 위치 `+0.05m`, 기울기 `-5도`, 속도 `4Hz`이며 약 1.494초임. 상위 8개 조건의 30초 재실행에서도 바닥 도달함.
- 0.1초마다 입력을 변경하는 자동 탐색도 실행함. 키보드 입력 변화율을 제한한 탐색은 약 3.39초 뒤 바닥 도달했으며, 계산 간격을 1/720초로 줄인 동일 입력 재생은 약 1.84초에 바닥 도달함.
- 입력 목표값을 빠르게 변경하는 탐색에서는 1/360초 계산으로 10초 유지한 궤적이 나왔으나, 동일 궤적의 1/720초 재생은 약 1.58초에 바닥 도달함. 계산 간격에 따라 유지 여부가 바뀌므로 안정적인 성공으로 채택하지 않음.
- 탐색한 고정값과 시간별 궤적의 실패는 모든 가능한 입력이 실패한다는 수학적 증명이 아님. 현재 입력에서 재현 가능한 수동 유지 조건을 확보하지 못한 결과로 해석함.

### 4.3.3 별도 위치 제어의 가능 범위

- 실험 변경 범위: 반복 손동작을 끄고 수직 막대의 끝 높이를 1.14m로 고정함. 좌우 및 앞뒤 위치를 각각 `-0.42~+0.42m` 안에서 독립적으로 조절함. 쳇바퀴의 형상, 질량, 관성, 마찰, 중력과 접촉 계산은 기존 코드를 사용함. 균형 제어는 막대 위치에만 작용하며 쳇바퀴의 위치, 자세와 회전을 강제로 복원하지 않음.
- 상태 기반 제어: 쳇바퀴의 위치, 이동 속도와 각운동량으로 받치는 지점을 계산함. 자세만 보정한 초기 실험 72개 중 5개는 10초 유지했으나 상위 4개 모두 30초 이전 낙하함. 위치와 이동 속도 보정을 추가한 실험 90개 중 70개는 30초 유지 기준 통과함. 초당 60회 제어와 0.02초 응답 시정수 조건의 초기 탐색 결과임.
- 재검증 조건: 제어 계수 `gain=2`, `positionGain=2`, `velocityGain=6`, 초당 20회 보정, 위치 이동의 응답 시정수 0.14초와 막대 끝 속도 최대 0.12m/s 적용함. 1/360초, 1/720초와 1/1440초 계산에서 모두 30초 유지함. 2.5도 초기 기울기에서 최대 기울기 약 3.73~3.81도, 막대 끝의 최대 수평 이동 반경 약 9.15~9.19cm와 종료 회전 약 80.94~80.97rpm임.
- 교차 검사: 초기 기울기 2.5도, 5도와 8도를 두 방향으로 설정한 6개 조건 및 10초 시점에 네 방향 중 한 방향으로 0.032N s의 수평 충격량을 가한 4개 조건을 세 계산 간격에서 실행함. 총 30건 모두 30초 유지, 접촉 시간 비율 100%와 유한 상태 확인함. 외란은 중심에 가한 시험 충격량이며 0.32kg 질량에서 순간 수평 속도 변화 0.1m/s에 해당함. 모든 조건의 최대 기울기 약 9.78도, 막대 끝 최대 수평 이동 반경 약 26.74cm와 이동 속도 최대 12cm/s로 설정 범위 안에 있음. 세 계산 간격 모두 성공했으나 엄밀한 수치 수렴 증명으로 해석하지 않음.

### 4.3.4 확보되지 않은 조건

- 같은 제어의 60초 연장 시험은 약 38.224초에 바닥 도달함. 실패 직전까지 유지한 결과를 지속적인 균형 유지로 기록하지 않음. 30초 유지 결과는 해당 검토 구간으로 한정함.
- 제어는 쳇바퀴의 계산 상태를 읽어 자동으로 막대 위치를 조절한 결과임. 사람의 관찰, 반응 시간과 화면 입력을 포함하는 수동 체험은 미검증임. 검증한 두 축의 위치 입력과 상태 기반 제어는 현재 HTML에 미구현임.
- 현재 세 입력을 유지한 채 값의 범위만 넓히면 해결된다는 근거는 없음. 독립적인 앞뒤 제어를 포함한 입력 재설계, 긴 구간의 유지와 계산 간격별 검증 및 사람의 조작 난이도 확인이 남음.
- 실제 천과 가죽의 변형, 마찰 및 기구 치수는 실측 보정되지 않음. 이 계산 실험으로 실제 버나의 균형 조건이 검증되었다고 판단하지 않음.

# 5 한계

- 자료의 구조를 평평한 양면과 속이 빈 테두리로 단순화한 모델임. 고정된 홈 제거 후 기존 손동작 함수로는 장시간 균형을 유지하지 못함. 평면 접촉, 재료별 질량 비율, 마찰, 공기 저항과 손동작은 실측 자료로 보정되지 않음. 현재 회전 유지와 낙하 수치를 실제 버나의 조건으로 일반화할 수 없음.
- 쳇바퀴 재질의 변형, 막대 휨, 실제 손의 균형 보정과 바닥 충돌은 정밀 재현 범위에 포함하지 않음. 바닥 접촉은 낙하 관찰을 위한 단순화임.
- 별도 위치 제어 실험의 30초 유지와 현재 화면의 수동 조작 가능성을 구분함. 60초 연장 시험 실패와 사람의 조작 미검증 사항은 [버나잡이 한 판: 확보되지 않은 조건](#434-확보되지-않은-조건)에 기록함.
- 던지기 힘과 받기 보조를 묶은 던질사위의 시범 입력임. 실제 버나잡이의 던지기 힘, 손동작과 받기 과정은 정밀 재현 여부 미확인임. 다른 사위는 미구현이며 사용자 체험 검토 전 상태로 Workspace에 유지함.
