# 1 개요

- **콘텐츠 정의**
	- 실물 막대로 게임 내 오브젝트를 돌리고 균형을 조절하며, 위에 놓인 덜미 미니어처 인형을 튕겨 내고 점수를 획득하는 키오스크 콘텐츠
- **개발 목적**
	- 무형문화유산의 형식과 포함된 의미를 사용자와 실시간으로 상호작용하며 체험 및 학습할 수 있는 수단 제공
- **핵심 시스템**
	- 오브젝트 회전과 균형 시스템
	- 미니어처 인형 튕기기 시스템
	- 시간과 단계 진행 시스템
	- 점수 누적 시스템
- **진행**
	- 버나, 대접, 대야의 순서로 조작 오브젝트 변경함.
	- 인형을 모두 튕겨 내거나 제한 시간이 경과하면 다음 단계로 전환함.
	- 오브젝트 낙하 시 제한 시간이 계속 경과하는 상태로 해당 단계 재시작함.
	- 대야 단계가 끝나면 정상 종료하고 마무리 화면 표시함.

# 2 핵심 시스템

## 2.1 오브젝트 회전과 균형 시스템

- 실물 막대의 움직임을 게임 내 막대에 연동하여 오브젝트를 회전시키고 막대 위에서 균형을 잡도록 하는 시스템임.
- 유저가 휘두르는 실물 막대의 움직임을 인식하고, 회전과 기울기를 게임 내 막대에 반영함.
- 게임 내 막대의 움직임을 막대 위 오브젝트에 전달하여 회전과 기울기, 균형 상태를 변화시킴.
- 조작 오브젝트는 단계별로 버나, 대접과 대야로 구성함.

## 2.2 미니어처 인형 튕기기 시스템

- 회전하는 오브젝트 위에 놓인 덜미 미니어처 인형을 불안정한 회전으로 밖으로 튕겨 내는 시스템임.
- 디스코 팡팡처럼 오브젝트의 회전과 기울기가 불안정해지는 정도에 따라 인형의 움직임과 튕겨 나가는 상태가 달라지도록 구성함.
- 유저는 오브젝트를 막대 위에 지지하며 회전과 기울기를 조절하여 인형을 튕겨 냄.
- 플레이 목표는 제한 시간 내 해당 단계의 인형을 모두 오브젝트 밖으로 튕겨 내는 것임.

## 2.3 시간과 단계 진행 시스템

- 인형 전부 이탈 또는 제한 시간 경과에 따라 단계를 마무리하는 시스템임.
- 버나와 대접 단계에서는 인형을 모두 튕겨 내거나 제한 시간이 경과하면 다음 단계로 전환함.
- 오브젝트가 낙하하면 제한 시간이 계속 경과하는 상태로 해당 단계 재시작함.
- 대야 단계에서는 인형을 모두 튕겨 내거나 제한 시간이 경과하면 정상 종료하고 마무리 화면 표시함.

## 2.4 점수 누적 시스템

- 오브젝트 유지 시간과 인형 이탈에 따라 점수를 누적하는 시스템임.
- 오브젝트가 막대 위에서 유지되는 동안 N초 단위로 기본 점수 적립함.
- 인형이 오브젝트 밖으로 튕겨 나가면 보너스 점수 획득함.

| 점수 구분 | 획득 조건 | 설정 |
|---|---|---|
| 기본 점수 | 오브젝트 유지 시간 N초 단위 | 적립 간격 N과 회당 점수량 미정임 |
| 보너스 점수 | 인형이 오브젝트 밖으로 튕겨 나감 | 인형 이탈 시 점수량 미정임 |

# 3 진행

## 3.1 단계 구성

| 단계 | 조작 오브젝트 | 플레이 목표 |
|---|---|---|
| 1단계 | 버나 | 제한 시간 내 덜미 미니어처 인형 모두 튕겨 내기 |
| 2단계 | 대접 | 제한 시간 내 덜미 미니어처 인형 모두 튕겨 내기 |
| 3단계 | 대야 | 제한 시간 내 덜미 미니어처 인형 모두 튕겨 내기 |

## 3.2 단계 내 진행

1. 해당 단계의 오브젝트 위에 덜미 미니어처 인형 배치함.
2. 단계의 제한 시간 시작함.
3. 유저의 실물 막대 움직임을 게임 내 막대에 연동하여 오브젝트의 회전과 균형을 조절하고, 유지 시간 N초 단위로 기본 점수 적립함.
4. 유저가 불안정한 회전을 만들어 인형을 오브젝트 밖으로 튕겨 내면 보너스 점수 획득함.
5. 인형을 모두 튕겨 내거나 제한 시간이 경과하면 단계 전환 조건 적용함.

## 3.3 단계 전환 조건

| 조건 | 처리 |
|---|---|
| 버나 또는 대접 단계에서 제한 시간 내 인형 전부 이탈 | 다음 단계로 전환함 |
| 버나 또는 대접 단계에서 제한 시간 경과 | 남은 인형 수와 관계없이 다음 단계로 전환함 |
| 오브젝트 자체가 막대에서 낙하 | 제한 시간이 계속 경과하는 상태로 해당 단계 재시작함 |
| 대야 단계의 인형 전부 이탈 또는 제한 시간 경과 | 정상 종료하고 마무리 화면 표시함 |

## 3.4 낙하와 재시작

- 오브젝트가 막대에서 떨어지면 해당 오브젝트를 다시 막대 위에 배치하고 현재 단계 재시작함.
- 낙하와 재시작 중에도 현재 단계의 타이머는 계속 경과함.
- 재시작 중 제한 시간이 끝나면 버나와 대접 단계는 다음 단계로 전환하고, 대야 단계는 정상 종료함.

## 3.5 마무리

- 대야 단계에서 인형을 모두 튕겨 내거나 제한 시간이 경과하면 정상 종료함.
- 정상 종료 후 마무리 화면 표시함.

# 4 미정 사항

- 실물 막대의 인식 장비와 인식 범위임.
- 단계별 제한 시간, 인형 수와 초기 배치임.
- 오브젝트 유지, 불안정한 회전과 인형 이탈을 판정하는 기준임.
- 점수 적립 간격 N, 기본 점수량과 인형 이탈 보너스 점수량임.
- 재시작 시 인형 복구 범위와 N초 미만의 유지 시간 처리임.
