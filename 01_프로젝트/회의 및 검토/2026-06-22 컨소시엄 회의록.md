# 3 주제별 논의

## 3.1 성과물 목표 (PD 요구로 컨소시엄 통일)

PD(과제 점검 전문가) 요청으로 성과물 표를 과학적, 기술적, 경제적 성과로 통일함. 7종 성과물의 목표와 담당 기관임.

| 성과물    | 목표                    | 담당                  |
| ------ | --------------------- | ------------------- |
| SCI 논문 | 건수 미명시                | 대학교                 |
| 특허     | 출원 6건(등록은 기간이 짧아 출원만) | KETI 2건, 나머지 큐랩과 셀빅 |
| SW 등록  | 10건                   | 큐랩과 셀빅 반반           |
| 사업화 건수 | 6건(기술 이전 등)           | 큐랩, 셀빅              |
| 사업화 매출 | 1억 원                  | 큐랩과 셀빅 반반           |
| 고용 창출  | 4명                    | 큐랩                  |
| 시제품 제작 | 3건                    | 큐랩(수요처 현장 제공)       |

## 3.2 데이터와 LLM 역할

- **KETI 역할**: 이미지와 3D 모션 기반으로 특징 추출과 모션 생성을 담당함. 텍스트 입력으로 모션을 생성하고, 택견은 아마추어 입력 모션을 입력받아서 이를 전문가 모션을 참고해 코칭용 모션을 생성해 코칭과 스코어링의 레퍼런스로 씀. 코칭 정밀도는 정량 목표가 없어 후처리 단계에서 다룸
- **LLM**: KETI도 LLM은 깊이 다루지 않음. 상용이든 오픈소스든 LLM을 붙이는 방향임. 온톨로지화와 학습 연동 프레임워크는 각 기관이 프로토타입을 만든 뒤 모여 통합 또는 별개 진행을 논의하기로 함(김용석 부장 제안)
- **모션 데이터 흐름**: 학습에는 모션캡처 데이터(FBX, 모션 파일 포맷)가 들어가고, 코칭과 추론에는 RGB 또는 뎁스 카메라(RGBD) 영상에서 추출한 3D가 들어감. 영상에서 3D 스켈레톤 추출은 연세대가 맡아 그 결과가 KETI로 연결됨
- **데이터 우선순위**: 무엇이 있는지부터 정리한 뒤 활용 방안을 함께 논의. 인터뷰 영상과 강의 영상이 있으면 빠르게 진행 가능

## 3.3 택견 데이터 확보

- **택견 단체**: 데이터에 두 단체가 연관됨. 경기도 택견회(안재식 이사)는 문헌 정리, 대한택견회(용인대 장 교수가 수석부회장)는 영상 보유와 이용 허락
- **영상**: 용인대가 2020~2021년 카메라 80대로 360도 회전 촬영한 표준수련체계 영상 보유(약 11테라). 대회 동작과 차이가 있어 표준화 재촬영을 검토 중. AI 허브에도 영상 자료 존재.
- **문헌**: 논문은 다수 존재. 동작 설명과 이미지는 PDF 작업과 정리가 필요(경기도 택견회)
- **모션 촬영**: 큐랩이 모션 슈트와 장갑으로 9월 중순~10월 용인대 학교에서 촬영(정답 데이터). 동작 리스트와 특징, 검수자 정리가 선행되어야 함
- **키 포인트 가중치**: 동작별 중요 프레임에 전문가가 가중치를 부여(엑셀)해 코칭 비교에 활용. 큐랩 태권도 방식 재사용
- **이용 허락**: 용인대 영상은 보유 주체인 대한택견회와 사용 범위 협의가 필요함

## 3.4 모션 인식 기술 범위 (연세대)

- **인원**: 알고리즘은 다인 기준 개발하되 지표는 2~3인까지 맞춰 진행. 1인이 정확도와 속도에 유리
- **연령**: 청소년 이상 성인 대상. 아동까지 넓히면 별도 모델 고려 필요
- **센서와 환경**: 서울랜드 같은 불특정 다수 환경 때문에 키오스크에 뎁스 카메라 설치. 실시간 세그멘테이션에 RGBD 활용
- **손 동작 한계**: 전신 싱글 카메라로는 손목까지가 현실적임(SMPL, 표준 인체 모델 기준). 손가락 추적은 장갑 센서나 구속 카메라가 필요해 별도 RnD 과제로 둠. 택견은 손동작(주먹 쥐고 펴기, 손목)이 중요해 추후 보완 검토

## 3.5 콘텐츠와 도제 설계

- **체험과 학습 병행**: 무형유산 전승이라 체험만으로는 부족함. 택견과 남사당 모두 체험형과 학습형을 함께 설계
- **택견 단계화**: 표준수련체계가 있어 8급에서 1급, 단 체계로 단계화. 홀새김(혼자 동작)과 맞대거리(약속 겨루기) 모두 단계별 존재. 통과 기준 달성 시 다음 단계 진입 방식 검토
- **남사당**: 표준 커리큘럼이 없어(전수자 개인 전수) 난이도 수준으로만 구분. 같은 플랫폼이라 택견과 이질감이 크지 않게 맞춤 필요

## 3.6 실증과 거버넌스

- **국내**: 서울랜드(셀빅). 내년 진행, 여름쯤 먼저 신청
- **해외**: 한 곳. 태국 초등학교와 베트남 대학을 비교해 선정. 용인대 장 교수가 7월 5일 베트남 방문(대학 3곳과 영재고 MOU 예정)이라 베트남 가능성 부상. 실증은 가을, 인력이 직접 방문해야 함
- **거버넌스**: RFP의 다학제 요구에 따라 반기 1회 회의. 1차 포럼은 이 회의로 갈음하고, 필요 인원을 그때그때 초대. 데이터 구축 전 데이터 폼과 형식, 취득 항목을 정하는 실무 회의 필요

# 5 정합 확인과 변경점

이전 문서 대비 확정되거나 바뀐 사항임. 녹취는 STT(음성 인식) 기록이라 수치는 재확인이 필요함.

- SW 등록: 이 회의에서 10건으로 정리(큐랩과 셀빅 반반). 사전 안건 [[#4 미결과 후속 액션]]가 지적한 제안서 내부 불일치(5건 대 합계 4건)는 10건 기준으로 정리되는 방향. 정본(제안서, RFP) 반영 확인 필요
- 특허: 등록이 아닌 출원 6건으로 하향(기간 제약). KETI 2건
- LLM: KETI가 주 엔진이 아니라는 점은 분명해졌으나, 상용이든 오픈소스든 사용 가능하고 프레임워크와 온톨로지는 각자 프로토타입 후 결정하기로 함. 확정이 아니라 방향 정리 수준임 ([[01_프로젝트/회의 및 검토/2026-06-22 큐랩셀빅 사전회의]] 대비 진전)
- 해외 실증지: 태국과 베트남 비교로 정리. 사전 안건의 태국과 필리핀에서 필리핀이 빠지고 베트남이 부상
- 서울랜드 설문 인원: 이 회의에서는 인원이 언급되지 않음. 사전회의(약 500명)와 안건 문서(400명) 간 불일치는 미해소
