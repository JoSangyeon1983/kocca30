# 3 주제별 논의

## 3.1 플랫폼과 하드웨어

- **키오스크 구성안**: 가로형 65인치 모니터 + 뎁스 카메라(키넥트나 오르벡(Orbbec) 류) + 바닥 프로젝션 + 라이다(RPLiDAR 등 저가형) 검토. UI 선택은 터치 모니터로
- **규격 정리 주체**: 큐랩이 센서와 규격을 정하고 셀빅이 맞춤. 기존 큐랩의 케이팝 키오스크(65인치, 뎁스 카메라 장착 공간)와 셀빅 포토부스 키오스크(세로형) 자산을 기준으로 단일 규격화
- **바닥 프로젝션 활용**: 택견 스텝(품밟기) 위치 표시, 남사당 바닥 연출에 쓰되, 프로젝터는 끌 수 없어 전 콘텐츠에 기본 배경이나 이펙트를 깔기로
- **케이브 판단**: 공수 대비 사업성이 낮아 관람형으로 최소화. 서울랜드 시연의 전시 효과 확보용. 해외에는 케이브를 못 가져감

## 3.2 데이터와 LLM

- **택견 데이터**: 용인대 보유 영상, 문헌, 모션 데이터를 취득. 모션은 학교에서 별도 촬영 협의(큐랩이 용인대 장 교수에게 사전 요청)
- **남사당 데이터**: 보존회와 협의해 확보. 전문가 활용비 집행 전제
- **온톨로지 DB**: 택견과 남사당을 하나의 DB로 구조화하되, LLM 방식이 정해져야 구조 확정 가능
- **LLM 주체 혼선**: 당초 KETI가 LLM을 맡는 것으로 이해했으나 KETI가 자기 역할이 아니라는 기류. 셀빅 정영균 상무도 자체 구축 의견. 컨소시엄 회의에서 확인 필요
- **데이터 비용**: 취득보다 정제 비용이 큼. 모션 데이터는 취득 단가가 높아, 실제 쓸 분량만 정제하고 코칭용 정답 데이터로 한정. 정량지표에 데이터셋 품질과 양 기준이 없어 부담이 적음

## 3.3 콘텐츠별 하드웨어 쟁점 (남사당, 셀빅)

- **버나(접시돌리기)**: 실제 인식용 막대 도구 제작 검토. 분실과 관리, 충전 이슈로 개발사 시연용에 한정될 가능성
- **어름(줄타기)**: 밸런스 보드 또는 바닥 프로젝션(줄 그려 연출)로 대체 검토. 실제 줄은 전용 공간이 필요해 키오스크 앞 배치는 어려움
- **덜미(꼭두각시)**: 사진이나 AI로 자기 캐릭터(가면, 꼭두각시)를 만들어 인형놀이 + 포토. 사업화 가능성이 가장 높다고 봄
- **풍물(상모돌리기)**: 키넥트 인식 후 이펙트 부여. 하드웨어 영향이 적은 콘셉트 사안
- **포토부스**: 미러리스 카메라 대신 모션 센싱 카메라 1대로 처리. 인화 없이 QR 다운로드

## 3.4 모션 코칭과 KPI

- **코칭 방식**: 큐랩 태권도, 피트니스 방식 재사용. 전문가가 찍은 모션 특정 포인트 가중치로 관절 각도와 거리를 비교해 피드백. 코칭이라기보다 정확도 체크 로직에 가까움
- **코칭 가이드**: 전문가(대학)가 기준을 주면 큐랩이 시스템에 녹임. 완전 반영은 어렵고 어색하지 않은 수준 목표
- **KPI 측정 분담**: 특성 분류 정확도와 4D 생성 정확도는 KETI, 동작 분석 정확도는 연세대, 현장 실증과 서비스 만족도는 큐랩(설문)

## 3.5 실증

- **국내**: 서울랜드. 셀빅 네트워크로 협의. 플랫폼을 먼저 만들어 제안하는 방식. 컨택 시점은 통상 결과 발표 2~3개월 전이나, 일정을 당겨 내년 상반기에서 중순 사이를 목표로 함
- **해외**: 두 후보 중 택일. 준비에 시간이 오래 걸려 8월부터 착수 필요
	- 태국 초등학교: 큐랩이 3면 케이브와 키넥트 케이팝 공간을 이미 설치한 곳
	- 베트남 대학: 용인대 택견 커리큘럼 공유처. 성인 대상이라 운영에 유리
- **운영 보조**: 설문 인원에게 줄 기념품 검토. 실증 영상 확보가 결과 보고의 핵심

## 3.6 거버넌스와 1차연도 운영

- **검증위원회**: RFP 요구 사항. 위원 풀을 구성하되(택견은 협회 부회장인 교수, UX는 외부 전문가) 실제 운영은 6개월에 한 번 리뷰와 기록 중심. 필요 시 보존회와 실제 회의
- **1차연도 평가 대비**: 연차 평가 가능성에 대비해 돌아가는 콘텐츠를 시연하고, LLM은 데이터셋 구축 성과로 보고. 통합과 RnD 요소는 2차연도로
- **서버**: 결과 저장과 로그인 정도만 필요. 큐랩 또는 셀빅이 개발(동기화 없음)

# 5 정합 확인 필요

녹취 내용이 사전 안건이나 정본과 어긋나 확인이 필요한 항목임. 녹취는 STT 기록이라 수치는 원문 재확인이 필요함.

- 서울랜드 설문 규모: 녹취는 약 500명 언급, 사전 안건은 400명으로 기재. 정본 대조 필요
- 해외 실증지: 녹취는 태국 또는 베트남 검토, 안건 문서는 태국과 필리핀으로 기재. 계획 변경 여부 확인 필요
