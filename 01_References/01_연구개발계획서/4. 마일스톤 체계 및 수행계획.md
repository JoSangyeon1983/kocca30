# 1 자료 개요

- 연구개발계획의 기관별 결과물, 목표 일정과 점검 기준을 연차별로 정리한 마일스톤 요약.
- 1차연도 16개와 2차연도 18개, 총 34개 마일스톤의 계획 기록.
- 아래 결과물과 점검 방법은 예정 사항이며, 실제 수행이나 점검 통과를 의미하지 않음.

# 2 출처와 작성 방식

- 자료: 사용자가 제공한 `4. 마일스톤 체계 및 수행계획.hwpx`, 연구개발계획서 제4장. 원본 파일은 2026-10-07 사용자 요청으로 삭제. 정리 문서와 출처 식별 정보 보존, 현재 위키에서 원본 재대조 불가.
- 작성 방식: 대규모 언어 모델(LLM, Large Language Model)을 통한 병합 표의 텍스트화.
- 근거 위치: 1단계 1차연도 및 1단계 2차연도 마일스톤 표.

## 2.1 기술 용어

### 2.1.1 분석과 서비스

- 인공지능(AI, Artificial Intelligence), 소프트웨어(SW, Software), 기술성숙도(TRL, Technology Readiness Level).
- 콘텐츠 관리 시스템(CMS, Content Management System)과 서비스 연계 인터페이스(API, Application Programming Interface).
- 사용자 인터페이스(UI, User Interface)와 고객 경험(CX, Customer Experience).
- 소형 언어 모델(SLM, Small Language Model): 원문에서 제시한 경량화 모델.

### 2.1.2 생성과 체험

- 라반 동작 분석(LMA, Laban Movement Analysis).
- 4차원 가우시안 스플래팅(4DGS, 4D Gaussian Splatting).
- 초당 프레임 수(fps, Frames Per Second)와 가상현실(VR, Virtual Reality).

# 5 확인 범위와 미확인 사항

## 5.1 확인 범위

- 원문 5개 표 중 연차 구분 표와 본문 표의 병합 셀, 총 34개 항목 대조.
- 번호, 목표 일정, 수행기관과 점검 항목을 원문 열에 맞추어 확인.
- 별도 내장 이미지는 없으며 첫 페이지 미리보기로 표의 배치와 구성 확인.

## 5.2 확인이 필요한 표기

- 2차연도 원문 3.2의 오차 감소 및 요약 교정 고도화 일정은 `26.06 ~ 26.12`로 기재되어 2026년 일정으로 보존. 2차연도 점검 기준과의 연도 불일치 확인 필요.
- 2차연도 원문 5.3은 심화 콘텐츠 6종 개발로 표기하나 결과물 열은 살판, 어름, 군중, 풍물과 대련의 5개 이름만 열거하여 세부 구성 미확인.
- 자체평가 항목의 정량 판정 값, 햅틱 반응 지연시간의 구체적인 합격 기준과 데이터 수집 수량은 이 표에 모두 명시되지 않음.
- 다른 장의 월별 추진일정과 일부 목표 기간에 차이가 있어 각 원문 표기를 유지하며 최종 일정 확정 필요.
- 실제 산출물 존재, 시험 실행, 목표 달성과 기관의 수행 완료 여부 미확인.
