# 1 개요

소재의 마당과 등장인물 구성 참고: [남사당놀이 - 덧뵈기: 연회본](남사당놀이%20-%20덧뵈기.md#5-연회본).

<img src="../../../04_Assets/00_Images/덧뵈기/탈놀음 한바탕/탈놀음_개요_인포그래픽_v6.png">

- **콘텐츠 정의**
	- 남사당놀이 덧뵈기 3개 마당(옴탈잡이, 샌님잡이, 먹중잡이) 중 옴탈잡이 마당을 체험하는 키오스크 콘텐츠
		- 1차년도 개발 대상으로 옴탈잡이 우선 개발 진행
- **소재**
	- 남사당놀이의 덧뵈기는 여타 탈 관련 무형문화재에 비해 춤사위보다 마임과 재담 및 사회 풍자가 두드러지는 특징을 지님
	- 마당씻이 -> 옴탈잡이 -> 샌님잡이 -> 먹중잡이로 진행되나 각 마당은 독자적인 구성이며 마당씻이는 오프닝 성격이어서 본 체험에서는 제외함
	- 각 마당은 희극이라는 카테고리에 묶일 수 있으나 웃음을 유발하는 요인은 각자 다름 (옴탈잡이: 기괴한 존재 퇴치, 샌님잡이: 권위 전복, 먹중잡이: 위선 폭로)
- **개발 목적**
	- 유저에게 덧뵈기의 각 마당 별 재미 요소 체험 수단을 제공하여 마당 별 특성을 체험 및 학습할 수 있도록 함

# 3 공용 시스템

## 3.1 세션 데이터

### 3.1.1 개요

- **정의**
	- 세션 진행 중 필요한 상태, 선택 및 수행 기록 등을 통합 관리하는 데이터
- **목적**
	- 콘텐츠 진행에 필요한 데이터를 체계화하여 **진행 상태 관리 및 데이터 관리 편의성 향상**

### 3.1.2 구성

| 데이터   | 유형  | 값                                                   |
| ----- | --- | --------------------------------------------------- |
| 세션 ID | 시스템 | 세션마다 부여되는 고유 식별자                                    |
| 현재 언어 | 시스템 | 세션에 적용 중인 언어<br>(기본값: 한국어)                          |
| 현재 단계 | 시스템 | 현재 진행 중인 단계<br>(시작, 가이드, 이용 동의, 마당 선택, 탈놀음 체험, 마무리) |
| 에러 유형 | 시스템 | 에러 발생 시 확인된 에러 유형<br>(기본값: None)                    |
| 동의 내역 | 시스템 | 약관 버전, 동의 시각 기록                                     |
| 선택 마당 | 콘텐츠 | 유저가 선택한 마당의 식별자<br>(기본값: 옴탈잡이)                      |
| 체험 단계 | 콘텐츠 | 유저가 선택한 각 마당의 진행 단계                                 |
| 수행 기록 | 콘텐츠 | 탈놀음 체험 진행 점수                                        |

	- 비정상적인 상황에서 세션이 종료되지 않은 채 유지되는 것을 방지하여 키오스크 회전율 제고

## 3.5 바닥면 처리

### 3.5.1 개요

<img src="../../../04_Assets/00_Images/공통/키오스크 사용예.png">

- **정의**
	- 키오스크의 바닥면 투사 기능과 유저 동작 감지 기능을 연동하여 선택한 남사당놀이 종목에 맞는 이미지를 바닥에 투사하고 유저가 발을 디딘 위치에 시각 효과를 표시하는 상호작용 시스템
- **목적**
	- 바닥면까지 체험 영역으로 확장하여 선택한 종목의 분위기와 특징을 공간적으로 전달
	- 유저의 발 동작에 즉각적인 시각 피드백을 제공하여 체험의 몰입감과 참여감 향상

### 3.5.2 동작 방식

- **진행**
	- 선택한 마당과 체험 단계에 맞는 배경 이미지를 바닥에 투사
	- 센서로 유저의 발 위치를 감지하고 감지한 위치에 시각 효과를 표시
	- 유저가 움직이면 발 위치를 다시 감지하고 시각 효과의 표시 위치를 실시간으로 갱신
- **장비 연동**
	- 설치 시 프로젝터의 투사 좌표와 센서의 감지 좌표를 맞춰 하나의 체험 영역으로 설정
	- 투사 범위와 감지 방식 등 세부 기준은 프로젝터와 센서 선정 후 확정

## 3.6 유저 기반 모션 인식 시스템

### 3.6.1 개요

- **정의**
	- 카메라로 등록된 유저의 신체와 양손을 추적하고 손 움직임을 게임 입력으로 변환하는 시스템
- **진행**
	- 양손 중 지정 움직임 기준을 먼저 충족한 손을 입력 손으로 지정
	- 입력 손의 화면 위치에 손 위치 포인터 표시 후 원으로 충돌 영역 지정
	- 손 위치 포인터 영역과 관심 영역(ROI)의 충돌 판정
	- 현재 입력 종료 시 입력 손 해제 후 양손 다시 비교
- **목적**
	- 유저가 별도 컨트롤러 없이 직관적인 신체 동작으로 콘텐츠를 조작하게 함
	- 카메라 영상을 화면에 표시하지 않아도 유저가 자신의 입력 위치를 확인하게 함

#### 2) 유저 식별 및 등록

- 화면의 가이드라인을 기준으로 체험 위치에 선 유저 식별
- 식별된 유저를 현재 세션의 추적 대상으로 등록
	- 주변 인원과 구분하여 추적
- 식별 실패 시 2초 간격으로 N회 재시도 -> 최종 실패 시 종료 처리

#### 3) 추적

- 등록 유저의 신체와 양손 위치 추적
- 양손 위치를 화면 좌표로 변환
- 각 손의 이동 방향, 이동 거리, 이동 속도 산출
- 입력 손 지정되지 않은 경우 양손 움직임 비교 유지

#### 4) 입력 손 지정

- 한 손 이상 추적 성공 시 각 손의 이동 방향, 이동 거리, 이동 속도 산출
- 양손의 산출값을 각각 이동 기준값과 비교
	- 하나의 값이라도 기준값 초과 시 두 산출값 크기를 비교하여 움직임이 더 큰 손 지정
	- 두 값 모두 기준값 이하 시 현재 입력 손 유지
- 양손 모두 추적 실패 시 2초 간격으로 N회 재시도 -> 최종 실패 시 유저 인식 및 등록 재시도

#### 5) 손 위치 포인터 표시

- 입력 손의 화면 좌표에 손 위치 포인터(이하 포인터) 표시
	- 포인터는 충돌 판정에 쓰일 원형 충돌체를 포함함
- 입력 손의 움직임에 따라 포인터 위치 갱신
- 손 떨림과 인식값의 작은 변화는 보정 뒤 포인터에 반영

#### 6) ROI(관심 영역 / 판정 영역) 입력 판정

- ROI는 입력 판정을 위해 화면상에 설정하는 가상의 영역임
- 포인터 충돌체가 목표 ROI가 접촉 및 교차 시 충돌 판정
- 충돌 판정 시 포인터의 크기와 색상을 변경하여 결과 표시

#### 7) 게임 입력 변환

- 유효 판정 ROI에 연결된 입력 정보를 게임 입력으로 변환
- 각 ROI에 설정된 행동 실행

- 소재 키워드와 방식 키워드가 모두 선택 시 바로 판정 실행

	- 유효한 조합 성공 시 신분, 향락, 여색, 폭력, 사기 중 해당 내용을 폭로하고 관련 재담과 먹중의 반응 동작 진행

	- 먹중잡이의 핵심 재미인 위선 폭로에 증거를 조합하는 추리의 재미를 더함

- 증거 2개 선택 시 바로 판정 실행

- 조합 판정 후 성공 / 실패에 따른 재담 분기 적용

#### 3) 조합 성공

- 해당 위선 증거 조합 수집 완료 처리

##### (2) 다음 조합과 종료

#### 4) 조합 실패

- 조합 실패에 해당하는 재담 진행
- 증거 선택값 초기화 후 새로운 증거 조합 진행

### 3.8.3 설정

#### 1) 조합 판정 시스템

- 전달받은 증거 2개로 조합값 생성

- 조합 테이블에서 생성된 조합값 조회
- 조합값 조회 성공 여부를 반환

#### 2) 데이터 테이블 기반 제어

- 관리 및 진행을 데이터 테이블로 제어할 수 있어야 함

	- 증거 목록
	- 증거 조합 결과에 따른 재담 진행

# 7 마무리 진행

## 7.1 개요

마무리 진행은 결과 안내 및 종료로 구성되어 세션을 마무리하는 단계임

## 7.2 진행

### 7.2.1 결과 안내 및 종료

<img src="../../../04_Assets/00_Images/덧뵈기/탈놀음 한바탕/진행_마무리.png"  width="500">

#### 1) 결과 데이터 집계 및 확정

- 세션 데이터에서 현재 언어, 선택 마당 및 수행 기록 로드
- 선택 마당의 단계 별 수행 기록을 결과 화면에 표시할 항목으로 집계
	- 각 단계의 점수를 100점 기준으로 정규화 후 가중 평균 처리
- 집계 결과를 최종 결과 데이터로 확정
- 기록 없는 항목은 미수행 상태로 처리

#### 2) 결과 화면 표시

- 선택한 마당의 명칭과 최종 결과 요약을 현재 언어로 표시
- 확정된 결과 데이터를 마당별 결과 항목에 맞춰 표시

#### 3) 체험 종료 처리

- '처음으로' 버튼 터치 또는 화면 타임아웃 또는 미입력 타임아웃 실행 시 체험 종료 처리  진행
- 결과 화면의 추가 입력 차단하고 진행 중인 타이머와 대사 출력을 종료
- 서버에 해당 세션의 체험 종료 상태 기록
	- 2차년도 개발 사양
- 종료 처리 완료 시 세션 데이터 초기화 진행

#### 4) 세션 데이터 초기화

- 종료된 세션의 임시 데이터를 초기값으로 변경
- 키워드 및 증거 선택값, 진행 인디케이터와 타이머 상태 초기화
- 초기화 완료 후 시작 화면으로 이동
