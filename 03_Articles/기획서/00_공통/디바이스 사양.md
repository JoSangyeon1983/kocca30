# 1 개요

키오스크와 미디어 케이브의 하드웨어 구성, 검토 규격과 설치 조건을 정리하고 장비 선정, 제작과 구축 협의의 기준으로 활용함.

# 2 키오스크

택견과 남사당놀이의 체험용 공통 디바이스.

## 2.1 기본 구성

| 항목 | 구성 |
|---|---|
| 화면 | 가로형 모니터 |
| 입력 | 모션 인식용 뎁스 카메라 |
| 바닥 출력 | 프로젝터를 통한 발 위치 안내와 바닥 연출 |

기본 구성은 [2026-06-22_컨소시엄 회의록: 핵심 합의](<../../../01_References/90_회의록/2026-06-22_컨소시엄 회의록.md#2-핵심-합의>), 뎁스 카메라 사용은 [2026-06-22_컨소시엄 회의록: 모션 인식 기술 범위 (연세대)](<../../../01_References/90_회의록/2026-06-22_컨소시엄 회의록.md#34-모션-인식-기술-범위-연세대>)에서 확인함.

- 바닥 프로젝션: 상시 가동 전제로 논의함. [2026-06-22_큐랩셀빅 사전회의: 플랫폼과 하드웨어](<../../../01_References/90_회의록/2026-06-22_큐랩셀빅 사전회의.md#31-플랫폼과-하드웨어>) 참고함.
- 포토 촬영: 모션 인식 카메라 1대 활용, 별도 미러리스 카메라와 인화기 제외 구성안. [2026-06-22_큐랩셀빅 사전회의: 콘텐츠별 하드웨어 쟁점 (남사당, 셀빅)](<../../../01_References/90_회의록/2026-06-22_큐랩셀빅 사전회의.md#33-콘텐츠별-하드웨어-쟁점-남사당-셀빅>) 참고함.

## 2.2 검토 규격

| 항목 | 검토값 | 상태 |
|---|---|---|
| 모니터 | 65인치 터치 모니터 | 검토안, 최종 크기 미정 |
| 카메라 모델 | 키넥트 또는 오르벡(Orbbec) 계열 | 검토안, 모델 미정 |
| 라이다 | 저가형 RPLiDAR 등, 사람 위치 분할 보조 | 채택 미정 |
| 화면 비율 | 16:9 | 설계 가정, 확인 필요 |
| 바닥 투사 면적 | 약 2m × 2m | 설계 가정, 확인 필요 |

화면 크기, 터치와 센서 후보는 [2026-06-22_큐랩셀빅 사전회의: 플랫폼과 하드웨어](<../../../01_References/90_회의록/2026-06-22_큐랩셀빅 사전회의.md#31-플랫폼과-하드웨어>)의 검토안임. 화면 비율, 투사 면적과 라이다의 보조 용도는 기존 문서의 검토값이며 회의 근거 미확인임.

## 2.3 본체와 설치 검토안

기존 문서의 셀빅 설계 가정임. 실제 제작 규격과 설치 치수는 미확정 상태임.

| 항목        | 검토 내용                                                                 |
| --------- | --------------------------------------------------------------------- |
| 입출력 보조 장치 | 마이크와 스피커                                                              |
| 외관        | 화이트와 밝은 회색                                                            |
| 화면 거치     | 수직 거치, 틸트 없음. 약 2m 시청 거리 전제, 설치 높이 미정                                 |
| 카메라 조준    | 전방 약간 하향, 약 2m 거리의 전신 동작 포착 전제                                        |
| 연산 장치     | 현장 GPU(Graphics Processing Unit, 그래픽 처리 장치) PC 또는 서버 연산. 배치와 PC 사양 미정 |
| 하단 함체     | PC 수용 공간과 안정적인 베이스. 함체 깊이는 연산 장치 확정 후 결정                              |
| 방열과 유지보수  | 흡기와 배기 환기구, 먼지 필터, 점검과 교체용 도어                                         |

## 2.4 인식 조건

| 항목 | 회의에서 논의한 범위 |
|---|---|
| 입력 영상 | 색상과 깊이 영상으로 사람 영역 실시간 분리 |
| 인원 | 다인 인식 알고리즘, 평가 지표는 2~3인 범위. 1인 인식이 정확도와 속도에 유리 |
| 대상 연령 | 청소년 이상, 성인 포함. 아동 대상은 별도 모델 검토 필요 |
| 손 동작 | 전신 싱글 카메라 기준 손목까지 인식. 손가락 추적은 장갑 센서나 추가 카메라 등 별도 대응 검토 |
