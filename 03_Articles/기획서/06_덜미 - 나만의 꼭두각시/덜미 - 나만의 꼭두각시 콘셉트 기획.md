# 1 개요

소재의 마당과 등장인물 구성 참고: [남사당놀이 - 덜미: 인형의 종류 및 줄거리](../../../01_References/02_남사당놀이/남사당놀이%20-%20덜미.md#1-인형의-종류-및-줄거리).

<img src="../../../04_Assets/00_Images/덜미/나만의 꼭두각시/꼭두각시_개요_인포그래픽_v5.png">

- **콘텐츠 정의**
	- 남사당놀이 덜미 2개 마당 7개 거리 중 꼭두각시 거리를 체험하는 키오스크 콘텐츠
- **개발 목적**
	- 무형문화유산의 형식과 포함된 의미를 사용자와 실시간으로 상호작용하며 체험 및 학습할 수 있는 수단 제공
- **핵심 시스템**
	- 조종 원리 시각화 시스템
		-  유저 동작을 외형 인형과 구조 인형에 동시에 연동하여 움직임 및 조작 원리 시각화
			- 조작 체험 구현의 경우 난이도가 높기 때문에 체험 대신 구조 학습 수단 제공
	- 병렬 서사 시스템
		- 전경의 유저 인형과 원경의 덜미 인형극을 병렬로 진행하며 이야기의 큰 흐름은 유지하면서 유저 행동이 세부 진행을 바꿔 두 장면이 합쳐진 웃음을 만드는 시스템
			- 유저의 체험에 큰 제약을 두지 않으면서 인형극 진행에 복잡한 분기를 두지 않아 매끄러운 진행 유도
	- 유저 성향 평가 시스템
		- 유저의 행동을 토대로 성향을 평가하여 마무리 화면에 표시
			- 병렬 서사 시스템에서 유저가 한 행동과 유저의 성향을 연결시켜 유저의 행동에 의미 부여
	- 사진 기반 인형 생성 시스템
		- 유저의 얼굴 촬영 뒤 생성형 AI를 이용하여 목각인형으로 변환
			- 병렬 서사 시스템에서 사용할 유저 인형이 필요하며 몰입감을 높이기 위해 공통 인형 대신 유저 전용 인형 사용
- **진행**
	- 현대 사람들도 공감하기 쉬운 치정극이라는 소재와 간단한 구성(박첨지, 꼭두각시, 덜머리집)을 가진 꼭두각시 거리를 우선 개발

# 2 핵심 시스템

## 2.1 조종 원리 시각화 시스템

<img src="../../../04_Assets/00_Images/덜미/나만의 꼭두각시/조종_원리_시각화_인포그래픽_v4.png">

- **정의**
	- 유저 동작을 외형 인형과 내부 조종 구조를 보여주는 구조 인형에 동시에 연동하는 시스템
- **목적**
	- 유저에게 인형의 움직임과 내부 구조의 관계를 동시에 보여주어서 유저가 인형 조작 원리를 이해할 수 있도록 함
	- 실제 손동작 조작을 재현하는 어려움을 줄이고 몸동작으로 쉽게 배울 수 있도록 함
- **동작 방식**
	- 유저의 이동, 몸 기울이기, 팔 휘두르기 등 동작 인식
	- 인식한 동작에 맞춰 외형 인형과 구조 인형 동시 조작
	- 외형 인형은 겉의 움직임을, 구조 인형은 그 움직임을 만드는 내부 조작 부위 작동 시각화

## 2.2 병렬 서사 시스템

<img src="../../../04_Assets/00_Images/덜미/나만의 꼭두각시/병렬_서사_시스템_인포그래픽_v3.png">

- **정의**
	- 전경의 유저 인형과 원경의 덜미 인형극을 병렬로 진행하고 유저 행동을 원경의 세부 진행에 반영하는 시스템
- **목적**
	- 유저의 행동을 폭넓게 허용하면서 이야기의 큰 흐름을 유지함
	- 유저 행동과 인형극의 반응이 어우러져 웃음을 만들고 몰입감을 높임
- **동작 방식**
	- 전경에는 유저 인형을, 원경에는 꼭두각시 거리의 인물과 사건을 보여줌
	- 유저 행동에 따라 원경 인물의 대사 등 세부 진행을 바꿈
	- 이야기의 주요 사건과 순서를 유지하며 다음 장면으로 이어 감

## 2.3 유저 성향 평가 시스템

<img src="../../../04_Assets/00_Images/덜미/나만의 꼭두각시/유저_성향_평가_인포그래픽_v2_upscale.png">

- **정의**
	- 체험 중 유저의 행동을 해석해 성향을 평가하고 마무리 화면에 보여주는 시스템
- **목적**
	- 인형극에 참여한 행동에 의미를 부여하고, 자신의 체험을 돌아보게 함
- **동작 방식**
	- 병렬 서사 진행 중 유저가 한 행동을 기록함
	- 기록한 행동을 평가 기준에 따라 해석해 체험에서 드러난 성향을 정리함
	- 마무리 화면에 성향과 그 근거가 된 행동을 함께 보여줌

# 3 진행

## 3.1 사진 기반 인형 생성

- 유저 사진 촬영 후 인형 생성
- 생성 대기하는 동안 덜미 인형 제작 과정, 덜미막 조립, 덜미 고사, 박첨지 유람 거리, 절짓고 허무는 거리 영상을 무작위순으로 반복 재생

## 3.2 꼭두각시 거리

### 3.2.1 꼭두각시와 덜머리집 싸움

- 원경
	- 박첨지가 조강지처인 꼭두각시와 재회하고 첩인 덜머리집 소개
	- 꼭두각시와 덜머리집 싸움
- 전경
	- 오브젝트들이 놓여 있고 유저가 움직여서 오브젝트와 충돌하면 산받이가 대사 진행
		- 그거 OO 아녀? 박첨지가 덜머리집에게 준 건가? 누구한테 줄건가? 아니면 저어기 멀리 던져버릴 수도 있네.
	- 오브젝트 예시
		- 노리개 -> 꼭두각시에게 주면 싸움 부추김 시도
		- 찬물 -> 꼭두각시에게 주면 싸움 중재 시도이나 꼭두각시가 덜머리집에게 끼얹음
		- 부채 -> 꼭두각시에게 주면 싸움 중재 시도이나 꼭두각시가 덜머리집에게 던짐
		- 비녀 -> 꼭두각시에게 주면 싸움 부추김 시도

### 3.2.2 재산 분배

#### 1) 원경

- 꼭두각시가 집 나가겠으니 재산을 나누어달라고 요청
- 박첨지는 좋은 것은 덜머리집에게, 안 좋은 것은 꼭두각시에게 분배

#### 2) 전경

- 박첨지가 재산을 말할 때마다 재산 아이콘이 중앙에 표시
- 유저는 박첨지의 재산을 꼭두각시나 덜머리집에게 주거나 저 멀리 날려버리거나 자신이 챙길 수 있음

#### 3) 표시할 재산 아이콘

##### (1) 살림 재산

- 오동 장롱 반다지
- 자개 함롱 귀다지
- 깨진 매운독
- 부적가리

##### (2) 땅문서

- 천석지기 땅문서
- 세마지기 땅문서

### 3.2.3 노잣돈 요구

- 원경
	- 꼭두각시가 금강산으로 떠나 중이 되겠다고 박첨지에게 노잣돈 요구
	- 박첨지가 거부
- 전경
	- 박첨지가 없다고 한 노잣돈(엽전 꾸러미)가 화면 중앙에 표시
	- 유저는 꼭두각시나 박첨지에게 주거나 저 멀리 날려버리거나 자신이 챙길 수 있음

### 3.2.4 박첨지 울음

- 원경
	- 꼭두각시가 떠나고 박첨지가 전경으로 이동한 후 울음을 터트림
	- 왜 우냐는 질문에 꼭두각시가 떠나서 시원하다고 답함
- 전경
	- 유저는 박첨지를 다독이거나 후려갈길 수 있음
