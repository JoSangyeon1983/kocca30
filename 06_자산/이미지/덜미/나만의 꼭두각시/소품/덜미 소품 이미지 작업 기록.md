# 1 용도와 입력 범위

- 사용자 요청: 소품 9개를 독립적인 1:1 투명 PNG로 사용하고, 실사에 가까운 기존 결과를 투박한 목재와 종이 재질로 다시 생성함.
- 입력: [덜미 - 나만의 꼭두각시 기획서: 꼭두각시 체험 진행](<../../../../../04_상세 기획/덜미 - 나만의 꼭두각시/덜미 - 나만의 꼭두각시 기획서.md#7-꼭두각시-체험-진행>)의 소품 항목과 사용자의 재질 수정 지시임. 기획서 본문과 승인 상태는 변경하지 않음.
- 부적가리: 사용자가 설명한 화로의 불을 젓는 긴 부지깽이 막대로 표현함.
- 스타일 참조: 먼저 수정한 찬물 그릇의 거친 조각면, 종이 덧붙임, 무광 물감과 굵은 붓 자국을 나머지 8개에 함께 입력함. 소품의 종류와 큰 외곽은 각 기존 이미지에서 참조함.

# 2 재질 수정 기준

| 대상 | 적용한 외형 |
|---|---|
| 찬물 그릇 | 투박한 목재 그릇, 물을 나타내는 푸른 종이판과 흰 붓 물결 |
| 노리개 | 목재 매듭과 장식, 넓은 종이 술 |
| 반다지, 함롱 | 거친 판재와 칠한 부속, 자개를 나타내는 종이 꽃과 잎 |
| 깨진 매운독, 땅문서 | 겹친 한지와 종이 단면, 단순한 그림과 균열 |
| 엽전 꾸러미, 부적가리 | 칠한 목재 원판과 종이 끈, 각진 목재 막대와 검은 그을음 표현 |

- 직접 시각 검수: 9개 모두 거친 목재와 종이의 조형, 무광 채색, 단일 소품과 전체 형태를 확인함. 실제 금속, 비단과 옥의 광택 및 투명 물 표현을 제거하는 방향으로 수정함.
- 파일 검수: PNG 9개 전체 디코딩, 1:1, RGBA와 알파 0~255, 생성 출력과 반영본 해시 일치 확인함. 알파 128 이상 형태는 화면 경계 안에 있음.
- 생성 출력의 알파를 보존함. 매우 약한 반투명 픽셀과 정밀 배경 합성은 별도 확인 범위이며 파일 재단이나 이미지 후처리는 수행하지 않음.
- 땅문서의 그림과 인장, 엽전 무늬는 게임 리소스의 가상 표현임. 실제 유물의 문자나 양식 고증은 수행하지 않음.
- 정보그래픽이 아닌 소품 단독 이미지로 별도 설명 라벨은 없으며 블라인드 문자 전사는 수행하지 않음. 게임 엔진 가져오기, 피벗과 충돌체 및 사용자 채택은 미확인임.
