# 1 목적과 입력 범위

- 현재 동작 파일은 6절의 개별 러프 PNG 01~08임. 사용자 지시에 따라 한 장으로 합치지 않음. 체형의 원본 기준은 [동일 시작 및 종료 이미지](<꺽쇠 입장춤 시작과 종료.png>) 하나이며 시작과 종료 PNG는 변경하지 않음. 이전 8칸은 이 이미지와 화풍 및 신체 비율이 달라 미채택한 결과임.

- 사용자가 영상 입력을 제외하고 시작 이미지와 동일한 종료 이미지, 동작 스토리보드와 캐릭터 시트만 사용하는 방식으로 변경함. 이번 작업은 원본 영상 분석과 8칸 동작 레퍼런스 이미지 제작임. 새 영상 생성은 수행하지 않음.
- 동작의 유일한 기준은 사용자 원본 꺽쇠_입장춤_0.mp4의 17초임. 현재 러프 입력은 시작과 종료 PNG, 원본의 해당 자세 1장 및 02~08의 공통 러프 표현을 위한 01 이미지임. 이전 서 있는 자세 PNG와 4면 시트 및 미채택 8칸은 현재 러프 생성 입력에서 제외함. 과거 생성 영상이나 다른 춤 문서는 동작 근거로 사용하지 않음.
- 사용자가 직접 지정한 작업 공간 원본과 산출물 PNG를 해당 자산 제작 입력으로만 사용함. 다른 기획의 채택이나 승인으로 확대하지 않음.

