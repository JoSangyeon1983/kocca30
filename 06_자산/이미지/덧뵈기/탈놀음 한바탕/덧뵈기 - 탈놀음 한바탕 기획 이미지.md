# 3 입력 자료와 생성 또는 편집 방법

- 현재 위키에 추가된 파일 자체를 확인. 제작 원자료, 생성 도구, 프롬프트와 편집 이력 미확인.
- 확인된 제작 근거 문서가 없어 `sources: []` 유지. 표시용 파일 목록은 `asset_files`로 관리.
- 이번 위키 반영 과정에서 이미지 재생성, 크기 변경과 파일 이동 없음.

# 4 검토 결과와 한계

- 파일의 존재, PNG 식별 정보, 이미지 크기와 실제 디코딩 확인.
- 원본 SHA-256(Secure Hash Algorithm 256-bit) 해시를 기준으로 반영 전후 내용 보존 검사.
- 기획서 연결과 원본 규격의 확인 범위이며, 이미지 내용의 사실성, 기획의 최종 채택과 화면 구현 결과는 미검증.

# 5 옴탈 SD 상태 이미지 제작

- 요청: 사용자 제공 옴탈_SD.png의 외형을 유지한 대기, 버티기, 버티기 풀림 이미지 3개 제작함.
- 입력: 같은 폴더의 옴탈_SD.png를 직접 확인하고 각 생성 호출의 외형 참조로 전달함. 사용자 지정 이미지는 편집 입력이며 기획 근거 채택과 구분함.
- 대기 자세 참고: [도쿠가와 미술관의 미카타가하라 전역화상](https://www.tokugawa-art-museum.jp/collections/徳川家康画像（三方ヶ原戦役画像）/)의 불만스러운 분위기를 제스처 참고로 사용함. 의복과 인물 정체성은 옴탈 기준 유지함.
- 도구: 내장 image_gen, 각 상태별 1회 생성함. transparent_background=true, 16:9 요청함. 실제 모델명은 반환에서 확인되지 않음.
- 직접 시각 검수: 대기는 정면의 불만스러운 표정과 턱 괴기, 버티기는 화면 좌측을 향한 웅크린 자세, 버티기 풀림은 목덜미가 들리고 두 팔과 두 발이 처지는 자세 확인함. 붉은 탈, 삿갓, 검은 옷, 붉은 띠와 흰 바지 유지함. 문자와 로고는 관찰되지 않음.
- 지정 문자열: 없음. 별도 컨텍스트의 블라인드 전사는 사용 가능한 별도 검수 도구가 없어 미수행함. 사용자 검토 전 초안이며 실제 게임 표시 크기 검수는 미수행함.
- 원본 옴탈_SD.png는 변경하지 않음. 기존 39개 이미지의 당시 검수 기록과 이번 생성 검수 범위를 구분함.
