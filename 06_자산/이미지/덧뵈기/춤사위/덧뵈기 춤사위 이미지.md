# 1 용도와 입력

- 사용자가 별도로 정리한 기존 춤사위 이미지 23장의 관리 기록임. [덧뵈기 춤사위](<../../../../05_참고 자료/덧뵈기 춤사위.md>)의 해당 동작 설명에 각 파일을 한 번씩 삽입함.
- 입력 원자료는 사용자 지정 `50_춤사위_01.png`부터 `50_춤사위_16.png`까지 16장이며, 아래 도해는 그중 사진과 장단표가 있는 14장에 대응함.
- 이미지 생성, 재편집, 파일 이동과 이름 변경은 수행하지 않음. 사용자가 정리한 파일을 그대로 연결하며, 최초 분리 작업의 도구와 상세 설정은 미확인임.

# 3 검토 결과와 한계

## 3.1 파일과 삽입 검토

- 원자료 16장과 자산 23장 모두 실제 파일 열기와 디코딩을 확인함. 자산의 사진 순서와 장단표를 원자료의 해당 도해와 직접 대조함.
- 23장의 파일 목록, 실제 규격, 본문의 23개 삽입 링크와 경로를 대조함. 참고 문서에는 자산 폴더의 파일만 삽입함.
- 입력 이미지의 SHA-256 기준값을 작업 시작 시 수집하고 종료 시 다시 대조하여 원자료와 자산의 보존을 확인함.

## 3.2 미확인 범위

- 원문 13번, 23번, 24번과 25번은 독립 도해가 없으며 별도 이미지 생성이나 다른 번호 도해의 전용을 수행하지 않음. 7번은 패턴 두 장이므로 번호 항목 26개와 자산 23장의 수량이 다름.
- 스캔된 사진과 장단표를 담은 기존 이미지임. 사진 사이의 연속 동작, 촬영 조건과 정확한 색상 및 원전 전체와의 일치는 미검증임.
- 새 이미지를 생성하지 않아 생성 프롬프트, 모델과 생성 설정은 해당 없음. 기존 파일 정리의 출처 대응과 표시용 첨부는 기획 채택의 근거가 아님.
